## 追記の作法

1. **1 項目は数行。** 事実と、それがいつ効くかだけを書く。背景の説明を書かない。
2. **事実と推測を分ける。** 実機で確認していないことは「未検証」または「推測」と明記する。
   確認したものは、いつ・どの版で確認したかを添える。
3. **設計書と重複させない。** 設計書に書いてあることは書かない。
   書くのは「設計書が採らなかった／触れていない」ものに限る。
4. **章立ては変えず、既存の表に行を足す。** 新しい章が要ると思ったら、まず既存のどれかに入らないかを見る。
5. 日本語で書く。ファイル名・関数名・変数名・キー名は英語。
6. 機微情報（実在のメールアドレス・ホスト名・社員 ID）を書かない。

ここには結論だけを置き、再現手順は書かない。

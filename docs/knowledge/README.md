# ナレッジ

**外界の事実の置き場。**置くのは、**我々の設計が変わっても真であり続ける事実**である。
設計の正本に入れると肥大するが、捨てると再調査が要る知識がここに集まる。

**ここは完全に独立している。他のどの文書も参照しない。**
外界の事実は、定義上どこかを参照する必要がない。
**だから誰からでも参照してよい。**

## 追記の作法

1. **1 項目は数行。** 事実と、それがいつ効くかだけを書く。背景の説明を書かない。
2. **事実と推測を分ける。** 実機で確認していないことは「未検証」または「推測」と明記する。
   確認したものは、いつ・どの版で確認したかを添える。
3. **ここから外を参照しない。** 他の文書へのリンクも、他の文書の章番号も書かない。
   我々の設計に依存する記述（どう作るか・なぜそう決めたか）はここに置かない。
4. **章立ては変えず、既存の表に行を足す。** 新しい章が要ると思ったら、まず既存のどれかに入らないかを見る。
   新しい文書を足したときは、上の一覧に行を足す。
5. 日本語で書く。ファイル名・関数名・変数名・キー名は英語。
6. 機微情報（実在のメールアドレス・ホスト名・社員 ID）を書かない。

ここには結論だけを置き、再現手順は書かない。

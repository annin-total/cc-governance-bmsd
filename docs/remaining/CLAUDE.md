# CLAUDE.md - remaining

`remaining/` 配下を書き換えるときの規約。

## 置くもの・置かないもの

**置くのは完了条件があるものだけである。**やれば終わる・確かめれば白黒が付くものを指す。

| 置く | 置かない | 置き場 |
| --- | --- | --- |
| やれば終わる作業 | 完了条件が無いもの（条件が変われば再検討する選択肢） | `../decisions.md` |
| 確かめれば白黒が付くこと | やっても終わらないこと（受け入れている限界） | `../decisions.md` |
| — | 外界の事実 | `../knowledge/` |

**「いつ終わったと言えるか」が書けない項目は、ここに置けない。**

## どの文書に置くか

| 文書 | 境界 |
| --- | --- |
| `deploy.md` | 実行基盤に到達しないとできない作業 |
| `distribution.md` | 配布経路に到達しないとできない作業 |
| `unverified.md` | 確かめれば白黒が付くこと |

## 参照規約

**この配下は成果物ではない。`docs/CLAUDE.md` を除き、他のドキュメント・実装コード・設定ファイル・
コミットメッセージから参照してはならない。**`../decisions.md` とは互いに参照してよい。

**ここから `../` 配下の他の文書を参照するのは構わない。**

## 進捗があったときの更新

**項目の状態が変わったら、必ずこの表のどれかを行う。書き足すだけにしない。**

| 起きたこと | すること |
| --- | --- |
| 作業が終わった | **その項目を消す。**「完了」と書き残さない |
| 確かめて白黒が付いた | 項目を消す。**結果が外界の事実なら `../knowledge/` へ移す** |
| 確かめた結果、やっても終わらないと分かった | **`../decisions.md` へ移す。**消さない |
| 新しい残作業が分かった | ここに足す。**完了条件を必ず書く** |
| 文書の項目が 0 になった | **その文書を消し、`README.md` の一覧からも外す** |
| すべての文書が消えた | **このディレクトリごと消し、`docs/CLAUDE.md` の記述からも外す** |

## 書き方

1. **何を・なぜ・どう確かめれば終わりか**が分かる粒度で書く。
2. **実機で確認済みのことと未検証のことを、はっきり区別する。**

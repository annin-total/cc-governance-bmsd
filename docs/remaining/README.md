# 残っている作業

**まだ終わっていない作業だけ**を置く。ここにあるものがすべて片付いたら、
**このディレクトリは丸ごと削除してよい。**

`../limitations.md`（既知の限界）は残り続ける。あちらは「やっても終わらないこと」であり、
作業が片付いても消えない。**この境界を明確にするために、残作業だけをサブディレクトリへ分けている。**

## 一覧

| 文書 | 中身 |
| --- | --- |
| [deploy.md](deploy.md) | 実行基盤への到達が要る作業 |
| [distribution.md](distribution.md) | 社内リポジトリへの到達が要る配布の作業 |
| [unverified.md](unverified.md) | 未検証のまま残っていること |

## 書き方

1. **何を・なぜ・どう確かめれば終わりか**が分かる粒度で書く。
2. **実機で確認済みのことと未検証のことを、はっきり区別する。**
3. 片付いた項目は消す。「完了」と書き残さない。

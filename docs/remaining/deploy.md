# 実行基盤への到達が要る作業

開発機からは実行基盤に到達できないため、到達できる端末で行う。手順は `../guide/deploy.md`
にある。ここにあるのは、まだ 1 度も通していない確認と、結果で分岐する判断である。
観測した結果は `../guide/deploy.md` に反映し、この文書から項目を消す。

## 疎通用の Function で手順を 1 回通す

`../guide/deploy.md` の手順を、疎通の確認まで 1 回通す。本番の Function は同じ設定で
別に作り、疎通用は残す（基盤側の変更を先に試せる）。途中で次を確かめる。

- 依存の install に使うコマンドが `pip` か `pip3` か。Open Terminal で
  `command -v pip; command -v pip3` を実行し、`entry.sh` が書いている方が PATH に無ければ直す
- 前段が公開サブパスを剥がすか剥がさないか。`BASE_PATH` を空にして公開サブパス付きの URL を
  叩いた応答コードで分かる。**どちらでも設定も実装も変えない**（ラッパは `PATH_INFO` が
  `BASE_PATH` で始まるときだけ剥がす）が、どちらだったかを記録する
- プロセスの作業ディレクトリが `server/` であること。崩れると契約の複製の検査が成立しない

**完了条件** — 疎通の確認がすべて通り、上の 3 点の観測が記録されていること。

## 起動時間とアイドル停止で、端末の送信タイムアウトを判定する

端末の送信は切り離されたプロセスで行われるため、コールドスタート自体は利用者を待たせない。
問題になるのは、所要時間が端末の POST タイムアウト（60 秒）を超えることだけである。
短すぎるタイムアウトは spool を溜め、上限による破棄を早める。

- スクリプト開始から待受までの所要時間（依存の install を含む）を測る
- 30 分・数時間・1 日放置したあとの初回応答時間を測り、停止と再起動の痕跡をログで見る

**完了条件** — どちらも 60 秒未満なら変更しない。60 秒以上なら `plugin/config.json` の
`timeout_sec` を実測より長い値へ引き上げる。

## MySQL 接続時の初期化を確かめる

SQLite でしか確認していない。MySQL が用意できない場合は SQLite で運用し、本番デプロイ前の宿題として残す。

| 事項 | 確かめること |
| --- | --- |
| `sql_require_primary_key` | 値が `0` なら変更しない。`1` なら主キーの無い 3 テーブルの `CREATE TABLE` が拒否される（INSERT は通る）。管理者にテーブルを用意してもらうか、設定を外してもらうかの 2 択であり、**勝手に決めずに判断を仰ぐ**。主キーは足さない（`events` は重複を前提とする append-only の設計） |
| 初期化 | DDL の適用・インデックスの存在確認・列の突き合わせが通ること。例外時のロールバック（SQLite では DDL が暗黙コミットのため確認できない） |
| ドライバの戻り値の列位置 | `SHOW INDEX` の `Key_name`、`SHOW COLUMNS` の `Field`。既定のカーソル（タプル返し）が前提 |
| 複数行 INSERT | プレースホルダ変換が実接続で通ること。1 行の桁超過で失敗する範囲（ドライバが文をどう組むかで変わる） |
| 置換後の文字列 | 符号化できない文字を置換した値が保存できること |
| `INTEGER` の桁 | 2038 年以降の `ts` が格納できないこと |
| インデックスのキー長 | 接続先の行フォーマットで作成が通ること |
| 統計情報の更新 | MySQL で動くこと |
| 8.0 系 | `sql_require_primary_key` と `CREATE INDEX IF NOT EXISTS` の扱いが 8.4 と同じか |

**完了条件** — 各行に観測した結果が 1 つ書かれていること。

## 本番でだけ確かめられること

- 日次のバックアップを運用に載せる。MySQL なら基盤側のバックアップの取得間隔を記録する
- CSV 取込での統計情報の更新にかかる時間を測る（取込の応答時間に上乗せされる）
- 基盤へ持って行く前に、手元で `docker build` / `docker run` を 1 度通す

**完了条件** — バックアップが 1 回取れ、所要時間と取得間隔が記録されていること。

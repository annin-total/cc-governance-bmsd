# g8 報告: effort と command_source（Claude Code 2.1.289、2026-10-04、macOS、本人のログイン、`-p`）

生ログは scratch にあったが、セッションの中断で失われた。以下は担当の報告の写しで、監督が生ログで照合した点を末尾に記す。

## effort（sonnet、同じターン）

| 条件 | classic Stop の `effort.level` | `turn.step` の `e.effort` | 一致 |
|---|---|---|---|
| (a) 指定なし | medium | medium | 一致 |
| (b) `--settings` で `effortLevel:"high"` | high | high | 一致 |
| (c) `--effort low` | low | low | 一致 |
| 参考: haiku | キー無し | absent | 両側とも欠落 |

- classic の `effort` は Stop の stdin にだけ入る。UserPromptSubmit の stdin には無い。スラッシュコマンドのターン（haiku）の Stop にも無い
- (a) の medium は、本人の `~/.claude/settings.json` の `effortLevel:"medium"` から来ている（モデルの既定ではない）
- `--settings` の値と `--effort` は、どちらも利用者 settings に勝った。`--effort` と `--settings` を同時に付けた比較はしていない
- 未検証: モデルの既定の effort（利用者 settings に effortLevel が無い状態）、xhigh・max・数値、サブエージェント、対話

## command_source

| 種類 | 呼び方 | classic の `command_source`（`expansion_type`） | `command.list` の source |
|---|---|---|---|
| 比較用プラグイン | `/feas-cmp:feasx` | plugin（slash_command） | plugin |
| プロジェクトの `.claude/commands/` | `/projx` | projectSettings（slash_command） | **user** |
| 利用者の skill（既存のもの、読むだけ） | `/karpathy-guidelines` | userSettings（slash_command） | user |
| MCP prompt | `/mcp__feasmcp__hello` | mcp（mcp_prompt） | mcp |
| 組み込み | `/context` | UserPromptExpansion も UserPromptSubmit も出ない | builtin |
| `--add-dir` の commands | `/addx` | 未知のコマンドで rc=1（commands は読まれない） | 一覧に無い |

- `command.list` では project と user を区別できない（どちらも user）
- MCP の名前: hook は `mcp__feasmcp__hello`、`command.run` の `e.command` と `command.list` の name は `feasmcp:hello (MCP)`
- 型 `CommandSource` は `builtin|plugin|user|mcp` の 4 値
- 未検証: policySettings・localSettings などの値

## 監督の照合

- 生ログで `command_source` の値 `projectSettings`・`userSettings`・`plugin`・`mcp` が各 1 件、`command.list` の source が `user`・`plugin`・`mcp`・`builtin`、
  MCP の名前の 2 つの表記、effort の `high`・`low`・`medium` を確かめた（セッションの中断の前）

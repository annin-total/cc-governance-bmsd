# 管理画面のローカル起動

集計サーバ（`server/`）を Docker で起動し、ブラウザで管理画面を見る。DB は SQLite。

先に Docker を起動しておく。macOS は `colima start`、Windows は Docker Desktop を起動する。

## 起動

`server/` で:

```bash
docker compose up -d --build
```

ブラウザで開く:

- URL: <http://127.0.0.1:15000/dev-admin/>
- ユーザー名: 入力不要
- パスワード: `dev-password`

値は `server/dev.env` と `server/compose.yaml` のダミー値。`127.0.0.1` だけで待ち受ける。

コードを変えたら、もう一度 `docker compose up -d --build`。本番モードはテンプレートをキャッシュするので、再起動しないと古い画面のまま。ブラウザは強制再読み込み（macOS は Cmd+Shift+R、Windows は Ctrl+Shift+R）。

ログ:

```bash
docker compose logs -f server
```

## データ投入（200 名・400 日）

### 1. 合成データを作る

`cc-governance-bmsd/`（リポジトリのルート）で。1〜2 分かかり、DB は約 400MB になる。作業場所は `.local/server-local/seed/`。

macOS:

```bash
rm -rf .local/server-local/seed && mkdir -p .local/server-local/seed
DB_DSN=sqlite:///.local/server-local/seed/ccgov-seed.db server/.venv/bin/python scripts/seed_dashboard.py --users 200 --days 400
server/.venv/bin/python scripts/seed_org_csv.py --users 200 --out .local/server-local/seed/ccgov-org.csv
```

Windows:

```powershell
Remove-Item -Recurse -Force .local\server-local\seed -ErrorAction Ignore; New-Item -ItemType Directory .local\server-local\seed | Out-Null
$env:DB_DSN = "sqlite:///.local/server-local/seed/ccgov-seed.db"
server\.venv\Scripts\python scripts\seed_dashboard.py --users 200 --days 400
Remove-Item Env:DB_DSN
server\.venv\Scripts\python scripts\seed_org_csv.py --users 200 --out .local\server-local\seed\ccgov-org.csv
```

`seed_dashboard.py` は、データが 1 行でも入っている DB には入れずに止まる。毎回作業場所を空にしてから作る。

`server/.venv` が無いときは、先に `server/` で:

macOS:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-dev.txt
```

Windows:

```powershell
py -m venv .venv; .venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt
```

### 2. DB を入れ替える

サーバを一度起動してから、`server/` で:

```bash
docker compose stop server
docker compose cp ../.local/server-local/seed/ccgov-seed.db server:/app/data/dev.db
docker compose start server
```

コンテナの DB は丸ごと置き換わる。中身は消える。

### 3. 組織 CSV を登録する

管理画面の「データと設定」→ 組織 CSV のフォームで:

- ファイル: `.local/server-local/seed/ccgov-org.csv`
- 月: 今月

290 行中 288 行が取り込まれる。2 行が漏れる理由は確かめていない。

### 4. 後片付け

`.local/server-local/seed/` を消す（macOS は `rm -rf`、Windows は `Remove-Item -Recurse -Force`）。

## 停止

`server/` で:

```bash
docker compose stop      # 止めるだけ。データは残る。再開は docker compose start
docker compose down      # コンテナも消す。データ（ボリューム）は残る
docker compose down -v   # データも消す。元に戻せない
```

空の状態から始め直すなら `docker compose down -v` → `docker compose up -d --build`。

作業が終わったら Docker を止める（macOS は `colima stop`、Windows は Docker Desktop を終了）。

## やってはいけないこと

- 中身を確かめずに `docker compose down -v`（投入したデータが消える）
- 検証のデータを本番の受信先に送る
- `dev.env` に本物のパスワードやトークンを書く

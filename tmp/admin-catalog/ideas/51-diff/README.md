| 31 との違い | 51 |
| --- | --- |
| 期間の終わり | 期間のページは利用明細の最終日（09/16）。設定の適用状況・収集の状態・サマリー・データと設定は今日（09/18）の時点で、帯は押せない |

| 基準超え | 要確認と注意の 2 つの大きな数字（案 32 の型）と、新規・離脱の見せ方 |
| 組織 CSV | 利用者の並ぶタブに「課」の列と部署の絞り込み、コストと利用者にタブ「部署ごと」、データと設定に月ごとの名簿の取り込み |

| 主な指標 | 横に期間を出さない（期間は帯の 1 か所だけ） |

## 切り替えの見方

画面の右下の「☰ 比較」を押すとパネルが開き、切り替えごとに値を選べる（既定と違う値の数をボタンに添える）。値は URL（`?g=G3&chart=K2` など）とタブを閉じるまで覚え、「この組み合わせの URL をコピー」で共有できる。

- 群 `g`・ヘッダーの高さ `hv`・コストのグラフ `chart`・基準超え `over`・サマリー `sum`・部署の絞り込み `df` とその部品 `dfs`・組織 CSV の取り込み `oi`・カレンダー `cal`・チップの色 `chip`・人数とコストの割合 `conc`・`concd`・`concAt`・古さの警告 `stale`・明細の遅れの見本 `lag`（中身は設計 3.1・4 章）
- 既定の値は通常の撮影（`shots/home-7.png` など）で見る。ほかの値は 1 枚ずつ `shots/cmp-<キー>-<値>.png`（カレンダーは開いた画面を全型、`cmp-hv-HV4-scrolled` はスクロール後）
- 古さの警告は利用明細が 3 日以上古いときだけ出るため、`cmp-lag-lag`（遅れの見本 × 警告あり）と `cmp-stale-W0`（遅れの見本 × 警告なし）で比べる
- 撮影は `python kit/shoot.py ideas/51-diff`、検査は `python kit/check.py ideas/51-diff`

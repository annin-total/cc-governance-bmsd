# 案 42 利用者から入る

## 41 との違い

- コストと利用者のカードを、利用者数 → 基準超え → コスト → 1 人 1 営業日あたり → 月末の見込み → 継続率 → モデル別の内訳 の順にする
- 利用者ごとのコスト・頻度・呼び出しを、コストと利用者のタブ「利用者ごとの一覧」1 つにまとめる。列の上の段で「利用明細」と「記録」を分け、両方の段は帯の期間で数える。12 か月では記録の段を出さない
- 利用状況のタブは 日ごとの利用・呼び出し先・セッションの大きさ・使われ方 の 4 つ。1 人あたりの利用日数とサブエージェントの起動のカードは、コストと利用者の「利用者ごとの一覧」へ移る
- 課ごとのタブに「記録」の段（1 人あたりの利用日数・1 人 1 日あたりの指示・スキルとコマンドの呼び出し）を足す。12 か月では記録の段を出さない
- 比較用の切り替えを置かない。見せ方は 41 の既定（O2・C31・V3・H1）で固定

利用者単位の分析を 1 か所で済ませる構成。ページの責務の分け方は 41 より崩れる（利用状況の一部の値がコストと利用者に入る）。

## ページごとのカードとタブ

| ページ | カード（表示の順） | タブ |
| --- | --- | --- |
| 概況 | 41 と同じ | なし |
| コストと利用者 | 利用者数 → 基準超え（7 日は日次・週次、28 日は月次）→ コスト → 1 人 1 営業日あたり → 月末の見込み → 継続率 → モデル別の内訳 | 利用者ごとの一覧・基準を超えた利用者・日ごとのコスト（12 か月は週ごとのコスト）・モデル・今月のコスト・月ごとの推移（12 か月）・課ごと（記録の段つき） |
| 利用状況 | 41 と同じ | 日ごとの利用・呼び出し先・セッションの大きさ・使われ方 |
| 設定の適用状況・設定の効果・収集の状態 | 41 と同じ | 41 と同じ |

- 2 列幅のコストの前に空いた列を 1 人 1 営業日あたりが埋めるため、画面ではコストより先に 1 人 1 営業日あたりが並ぶ
- キャッシュ読み込みの割合はコストと利用者のモデルのタブへ、利用日数とサブエージェントの起動は利用者ごとの一覧へ移る

## 切り替えの見方

切り替えは無い。`?over=` などを付けても見せ方は変わらない。

追加の画像: `user-all-*`（利用者ごとの一覧。7 日・12 か月・部で絞った 28 日）、`sections-rec-*`（課ごと。7 日・12 か月）、`go-activity-user-all`（利用状況の利用日数のカードを押した移り先）。

# 案 34 利用者から入る

設計（`../../concepts.md`）の 6 章の案 34。骨組み（ページ・問い・群・窓）は 31 と同じで、並びと利用者ごとのタブだけを変える。

- 概況: サマリー → 目安を超えた利用者（`over_limit`）・コストの多い利用者 → コスト → 今月 → 利用者 → 設定の適用。計 11 枚
- コストと利用者: 群の並びを 目安を超えた利用者 → コスト → 今月 → 利用者 にする。群の中のカードの並びは 31 のまま
- コストの多い利用者は `top_spenders_diff`（`top_spenders` の内訳に前との差を足したもの。札は 31 にもある）
- 利用者ごとの一覧 `user_all` がコストと利用者の `user_cost` を置き換え、利用状況の `user_use`・`user_calls` を外す。利用状況は 4 タブ
- 利用状況の `days_per_user`・`agent_launches` は、コストと利用者の `user_all` へ期間と基準日を引き継いで移る（`borrow`）
- `user_all` の列は設計の 16 列そのまま（利用者＋利用明細 6＋記録 9）。主な列に絞らないのは、表の中の横スクロールで収まり、
  `user_use`・`user_calls` から移る列を落とすと外したタブの問いに答えられなくなるため。よく使う呼び出し先の上位 3 つは入れない（`calls` で引く）
- 列の上の段で利用明細と記録を分け、段の見出しに各期間を出す。表の注記で、利用明細の段が 2 日早く終わることを書く。12 か月は利用明細の段だけ
- チップは悪化だけ印を付け、改善と中立は地の文字（`look.delta.worseOnly`）。絞り込みは 31 と同じく薄くする
- 撮影: `python kit/shoot.py ideas/34-users-first`（`shots/`）。`x-activity-*`・`x-user-all-*` は利用状況から移った先・表の右端・注意で絞った一覧
- 検査: `python kit/check.py ideas/34-users-first`
- 基準日を変えても値は変わらない（モックの制約。データは 09/18 の 1 時点だけ）

# 案 35 セッションを効果の隣に

設計（`../../concepts.md` 6 章）の案 35。案 31 からの差分だけを変え、概況と見せ方（`look`）は 31 と同じ。

- 狙い: 同じ指標の「今」と「守り始めた前後」を同じページに並べ、何の前後かを説明なしで分からせる
- 31 との差: `session_size`・`autocompact_sessions` の群「セッション」とタブ `session_size` を設定の効果へ移す。設定の効果に期間のタブが付き、群はセッション → しきい値の前後の順。`bypass_users` は利用状況の頻度の群へ。利用状況は 5 タブ、設定の効果は 3 タブ
- 設定の効果はページの `data` を持たず、群の窓（`rec`・`study`）から値を引く。12 か月ではセッションの群が注記だけになり、タブ `session_size` は「出しません」
- 強み: 利用状況が軽くなり、6 タブで切れていたタブ名（「利用者ごとの頻度とセ…」）が切れない。設定の効果が 2 群・3 タブになり薄さが和らぐ
- 弱み: 設定の効果に「セッションの大きさ（中央）」「自動コンパクトに達した割合」が 2 枚ずつ並ぶ（直近 7 日 79k と適用後 70k）。見出しが同じで窓だけが違い、前後差を効果と読む誘いが強い
- 弱み: 期間のタブが上の群だけに効き、下の群（期間は守り始めた日の前後で固定）は動かない。見出しの横の期間の注記でしか見分けられない
- 弱み: 利用状況の問い（リード文）は「セッションはどれだけ大きいか」のままで、セッションのカードは無い（骨組みの問いは全案共通のため変えていない）。確認なしモードが頻度の群に入るのは語として据わりが悪い
- 撮影で気づいたこと: 設定の効果のセッションの群は 2 枚で右半分が空く。タブの先頭はセッションの大きさ（直近）で、効果のページなのに前後のタブが 2 番目になる
- 撮影: `python kit/shoot.py ideas/35-session-by-effect`（`shots/`。設定の効果は 7・28・12m の 3 枚）。検査: `python kit/check.py ideas/35-session-by-effect`

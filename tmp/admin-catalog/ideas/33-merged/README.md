# 案 33 まとめて厚く

設計（`../../concepts.md` 6 章）の案 33。骨組み（ページ・問い・群・窓・タブ）は 31 と同じで、カードのまとめ方と見せ方だけを変える。

- 31 との差: 利用者 3 枚を `users_all`（使い始めた・離れた・継続率を行に）、呼び出し 4 枚を広い `calls_all`（4 行 × 回数・差・使った人）、セッション 3 枚を `session_all` にまとめる
- 基準を超えた利用者は 1 枚 `over_rows` に区分の行（7 日は日次・週次、28 日は月次）をまとめ、行ごとに要確認・注意の人数と札、新たに該当・外れたのチップ。大きな数字は無い
- 設定の適用 3 枚を `applied_all`、版 2 枚を `outdated_all` にまとめる。行ごとに人数と札を出し、カードの札は行の最も重いもの
- 概況は 7 枚（コスト 2・今月・基準を超えた利用者・利用者・設定の適用・古い版の利用者）。コストと利用者は 8 枚
- 見せ方: チップの値の後ろに語を添える（`look.delta.word`）。絞り込みは該当しないカードを隠す（`look.filter: "hide"`）
- 強み: 画面が短い。設定の適用が 1 枚で、すべて適用・未適用あり・未導入を並べて読める
- 弱み: 1 枚の中に状態の違う行が入り、札がカード単位でなく行単位になる。呼び出し・セッションの行には内訳のグラフが無い
- 撮影で気づいたこと: 古い版の利用者は大きな数字が無く、カードの中ほどが空く。設定の適用の添える数字が 2 行に折れる
- 基準日を変えても値は変わらない（モックの制約。データは 09/18 の 1 時点だけ）

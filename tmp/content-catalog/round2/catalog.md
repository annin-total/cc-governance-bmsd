# カードとタブの目録（第 2 弾）

第 2 弾の構成案が使うカードとタブを 1 つずつ確定したもの。**カードとタブの中身はこの目録で揃え、案はページ・群への並べ方だけを変える。**
定義の正本は `kit/catalog_cards.js`（窓とカード）・`kit/catalog_tabs.js`・`kit/catalog_tabs2.js`（タブ）で、ここの id と見出しはそれと一致させる。
全部を並べた見本は `ideas/00-sample/`（案ではない）。

見出しは画面の語で書き、比喩や目的の名前を使わない。コンテキストの自動の要約は「自動コンパクト」と呼ぶ（英字の Compact は hook 名を示すときだけ）。

## 窓

群の中のカードは同じ窓にする。窓はカードの定義（`win`）から決まり、群の見出しの横に期間と母集団を出す。

| 窓 | 期間 | 母集団 | 12 か月 |
| --- | --- | --- | --- |
| `rec` | 直近 N 日（今日まで）と前の N 日 | 記録を送った利用者 | 出さない（群の注記にカードの名前を並べる） |
| `rec7` | `rec` を 7 日に固定（期間を選べない群） | 同上 | 7 日の値のまま |
| `bill` | 利用明細の最終日までの N 日と前の N 日 | 利用明細にコストがあった利用者 | 直近 12 か月・週と暦月（前の期間と比べない） |
| `match` | 利用明細の最終日までの N 日 | 記録と利用明細の突き合わせ | 出さない |
| `match7` | `match` を 7 日に固定 | 同上 | 7 日の値のまま |
| `month` | 今月（利用明細の最終日まで）と前月 | 各月にコストがあった利用者 | 期間に依らない |
| `p30` | 直近 30 日・端末ごとに最新の報告 1 件 | 利用明細の最終日までの 30 日にコストがあった利用者（分母） | 期間に依らない |

| `now` | 現時点 | 取り込んだ利用明細 | 期間に依らない |

## 定義の書き方

各案は `ideas/NN-<slug>/` に `index.html`（`ideas/00-sample/index.html` の写し。書き換えない）と `ia.js` を置く。
`ia.js` はページ → 群 → カード id の並びと、タブ id の並びだけを書く。カードとタブの中身は `kit/catalog_*.js` にだけある。

```js
(() => {
  const { build } = window.CATALOG;
  window.IA = build({
    id: "NN-slug", name: "案 NN 名前",
    pages: [
      { id: "top", title: "トップ", lead: "…", refs: [{ page: "use", cards: ["active_users"] }, { page: "cost", cards: ["cost"] }] },
      { id: "use", title: "利用", lead: "…", periods: true,
        groups: [["記録", ["active_users", "days_per_user"]], ["利用明細", ["billed_users", "retention"]]],
        tabs: ["user_use", "daily_use"] },
      { id: "calls", title: "呼び出し", lead: "…", periods: true,
        groups: [["直近 7 日", ["skill_calls", "command_calls"], { win: "rec7" }]], tabs: ["user_calls"] },
    ],
  });
})();
```

- 群は `[見出し, [カード id], { win, note }]` か `{ label, cards, win, note }`。窓はカードの `win` から決まり、窓の違うカードを 1 つの群に入れるとコンソールにエラーを出す。`win: "rec7"`・`"match7"` で期間を 7 日に固定した群にできる
- 同じカードを 2 つのページに置くとエラーを出す（トップの参照は数えない）
- カードを押すと、定義の開くタブの候補のうちページにある最初のタブを開く。無ければ押せないカードになる
- 12 か月では、タブの `long` に従って差し替え・そのまま・出さないを決め、出るタブを先に並べる。`longOnly` のタブ（`months`）は 12 か月だけに出る
- トップは `refs: [{ page, cards }]` で他のページのカードを参照するだけで、中身を持たない。群は参照元のページ・群ごとに作り、見出しは「ページ名 · 群名」、窓の表記も参照元のまま出す。カードを押すと参照元のページのタブへ移る。期間の切り替えは、参照元に期間の効くページがあれば出す
- データと設定のページは `build` が末尾に足す
- 撮影は `kit/shoot.py ideas/NN-<slug> --out <置き場>`（コンソールのエラーか横スクロールがあれば終了コード 1）。値の雛形・部品・セルの種類は第 1 弾の `kit/README.md` のとおり

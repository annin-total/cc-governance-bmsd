# 案 09 利用とコストをまとめる

**狙い**: 量（人数・指示）と金額を 1 ページに置き、1 人あたり・1 指示あたりの単価で結ぶ。窓の違いは群で分ける。
- **利用とコスト** — どれだけ使われ、1 回あたりいくらか
- **スキルとコマンド** — どの機能が誰に使われているか
- **設定** — 配った設定が効いているか（しきい値の前後を含む）
- **端末と収集** — 端末が最新で、記録が届いているか
**今から消えるもの**: 概況・設定の効果のページ（設定へ）・確認なしモードのカード。**足すもの**: 単価（K31・K32）・定着度・コスト順位（T04）・使い方（T05）・ツール（T13）・記録の無い利用者（T32）。
**強み**: 使った量と金額を 1 ページで読める。単価の窓のずれを群の注記で出せる。
**弱み**: 利用とコストのページが 4 群・5 タブで重い。単価は利用明細が Claude Code 以外を含むと過大になる。12 か月では単価・記録の群が注記だけになる。
**足した値・部品**（`index.html` は kit の写しに `data-extra.js` の読み込みを 1 行足した）: `data-extra.js` に T32 の行（`m.uncollected_rows`: 利用明細だけの人と収集を止めた人を 1 表に）と、端末ごとの本体の版（`fixed.x.core_by_terminal` を端末の行に結合）。部品の足しは無い。
**足すと良い収集**: `turn_output_tokens`（利用明細を使わずに 1 応答あたりの量を出し、単価の窓のずれを避ける）。

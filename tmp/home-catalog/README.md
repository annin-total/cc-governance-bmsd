# 管理画面の概況のモック

管理画面の最初のページ「概況」の案を 12 個並べたもの。載せる中身の趣旨は決まっており、**カードの分け方・カードの中の構成・語・注目の導き方**を比べる。**一時的な文書で、採る案が決まったら消す。**

- 正本: `brief.md`（趣旨・色の決まり・警告の基準・ダミーの値）
- 各案: `ideas/NN-*/index.html`（1 ファイル完結、file:// で開ける）
- 画像: `shots/NN-*-first.png`（1280×800 の 1 画面目）、`shots/NN-*-full.png`（全体）
- 全案共通: 色が付くのは注意・要確認の印だけ。正常は灰。増減は矢印・符号・語（悪化・改善）で示し、色を使わない

| No | 系統 | 名前 | カードの分け方と狙い |
| --- | --- | --- | --- |
| 01 | 今の画面に忠実 | faithful | 1 趣旨 1 カード。今の概況に最も近い |
| 02 | | merged | コストの幅広 1 枚に 1 営業日・1 人 1 営業日・利用者を統計の行で持たせ、行ごとに印 |
| 03 | | charts | 小さい図が主役（推移の線・営業日の棒・1 人 1 つの四角・割合の帯）。サマリーは最下段 |
| 04 | | questions | 群の見出しを問いにし、カードを 8 枚に絞る |
| 05 | まとめて密度を上げる | group-cards | 群ごとに 1 枚の大きなカード（コスト・利用者・設定の適用・収集の状態） |
| 06 | | lead-figure | 主役の数字 1 つと脇の数字 2 つの主従カード 8 枚。1 画面目にカードが全部入る。サマリーは下 |
| 07 | | small-tables | カード 4 枚と、基準超え・設定の適用の小さな表 2 つ、収集の状態の帯 |
| 08 | | kpi-band | 数字 6 つの帯と、内訳の表 1 つの 2 段 |
| 09 | 注目の導き方を変える | attention-first | 注意・要確認のカードを先頭の段に寄せ、正常は後ろに小さく |
| 10 | | checklist | サマリーの直下に「確認すること」の一覧（どのカードが・なぜ。押すとカードへ） |
| 11 | | contrast | 並びは固定し、正常のカードを薄く小さく、注意・要確認を濃く大きく |
| 12 | | summary-lead | サマリーを紙面の主役にし、カードは下に控えめな格子 |

## 比べるときの注意

- 金額・モデルの割合は仮の値
- 総額と 1 営業日あたりは、営業日数が違う（今期 4・前 3）。判定は 1 営業日あたりの率で行い、総額の率（+49.3%）は判定しない
- 基準を超えた利用者の「日」は「基準日までの 7 日のいずれかの 1 日」と置いた
- カード全体がリンクのため、カードの中の人数や一覧への導線は見た目だけ（入れ子のリンクにできない）

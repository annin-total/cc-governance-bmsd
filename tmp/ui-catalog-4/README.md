# 管理画面デザイン・カタログ 第 4 弾

期間の切り替え・月末のコストの見込み・数値とツールチップ・エクスポートの**見せ方**を詰めたもの。**一時的な文書で、実装する形が決まったら消す。**中身（ページ・群・カード・タブ・指標）の見直しは扱わない。

- `ideas/00-baseline/`: 第 3 弾の評価で合意したことを全部入れた基準案（概況・スキル・コマンドの利用・エクスポート・設定の適用状況・設定の効果）。合意の一覧は `brief.md`
- `ideas/01〜12`: 基準案を写し、まだ決めていない見せ方を 1 つだけ変えた変奏案。変えた所以外は基準案と同じ
- 値はダミーデータ（40 人・400 日）。file:// で開ける。期間は URL の `?period=7|28|12m`
- 進め方と決まったことの記録は `PROGRESS.md`

## 基準案で仮に置いた値（実装で決め直す）

- 見込みを「—」にするのは経過 3 営業日未満。エラーのカードの「注意」は 1 件以上
- 休日のコストは次の営業日に含める（月末の休日は最後の営業日に）
- 表の金額は、列の最大が 1,000 以上なら列ごと整数。トークンの表の列は M・小数 2 桁
- ファイル選択の「Choose File」はヘッドレスのブラウザの表示で、実機では日本語になる
- 「利用」の群が 5 枚になり「確認なしモードの記録」が 2 行目に残る。中身の見直しで扱う

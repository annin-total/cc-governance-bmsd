# 09 エクスポートを格子で

- 名前: エクスポートを格子で（第 3 弾 13 を基準案の見た目で作り直したもの）。00 を写し、`parts/export.js`・`export.css` だけを変えた。ほかは 00 と同じ（画像も変えた所の 3 枚だけ。ほかは 00 の画像を見る）
- 変えた点: 「書き出す」の月の一覧の表を、暦年の 12 か月の格子（4 × 3）にした。マスはカードと同じ地・角丸・見出し（月名と「ZIP ↓」）で、4 表の合計の件数・件数の細い棒・大きさ（見込み）・「途中」「08/26 から」の注記。マスを押すとその月の ZIP を落とす。年は群の見出しの右の分段（2025 年・2026 年、既定は今年）で切り替える。取込は 00 と同じ
- 狙い: 年の中の位置で月を選べ、月ごとの量の増え方も格子で一目で分かる。操作は押すだけのまま
- 仮の判断: データの前の月は「記録なし」、先の月は「まだありません」の枠だけのマス。表ごとの件数（記録・設定の報告・エラー・利用明細）は格子では出さない（札で出すと幅 320px に収まらず、合意の札はカードの小さなグラフ用のため）
- 懸念: 表ごとの件数が見えなくなる。2025 年は 12 マス中 7 マスが空で寂しい。押すとすぐ落ちるので、押す前に中身を確かめる手段は下の注記だけ

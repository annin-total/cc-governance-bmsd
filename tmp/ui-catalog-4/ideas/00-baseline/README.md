# 00 基準案

- 名前: 基準案（合意 1〜10 をすべて入れたもの）。変奏案はこのフォルダを写し、下の「差し替える所」だけを変える
- 描画: window.DATA と DATA_EXTRA（`../../data/`）から JS で組み立てる。期間は `?period=7|28|12m` のリンクで読み直す（本実装のサーバ描画に合わせる）。タブ・絞り込み・並べ替えは `../../base/static/app.js` をそのまま使う。CSS も base の 3 本を読み、足した分だけをこのフォルダに置く

## 判断・仮の値

- 見込みのカード: 2 列（営業日あたり・1 人 1 営業日あたり）に「今月の値＋増減の印＋前月の値」、最下行に実績と経過営業日。見込みを「—」にする閾値は経過 3 営業日未満（仮）
- 1 人 1 営業日あたりの利用者は、その月に利用明細でコストがあった人（9 月は 09/28 まで 40 人、8 月 40 人）
- 今月のタブ: 休日のコストは次の営業日に含める（月末の休日は最後の営業日）。横軸は前月に合わせて 20 営業日まで。表の 18・19 は見込みの累積、20 は前月だけ
- 日ごとのコストのタブは期間に追従（第 3 弾 01 と同じ。今の画面の全期間 399 日ではない）
- 12 か月: 利用者のカードは 12 か月の重複なしの人数（40 人）。カードの折れ線は途中の週（1 日分）を除く。月の行は各月の最初の週の位置に暦月の値を書き、範囲の最初の 2025-09（2 日分）は出さない
- エラーのカードの「注意」は 1 件以上（今の画面の見た目に合わせた仮の値）。表の金額は列の最大が 1,000 以上なら列ごと整数
- 模型の制約: ファイル選択の「Choose File」はブラウザの言語による。取込は選んだ CSV をブラウザで数えるだけ

## 懸念

- 「利用」が 5 枚になり、2 行目に確認なしのカードが 1 枚だけ残る（第 3 弾 01 と同じ）

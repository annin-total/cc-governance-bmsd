# 04 月の帯で区切る 12 か月

- 名前: 月の帯で区切る 12 か月。基準案 00 の写しで、`parts/twelve.js` の `monthRow`（と凡例の文言）・`parts/twelve.css` だけを変えた。ほかは 00 と同じ
- 変えた点: 週ごとのコスト・利用者のグラフで、月の区切りの線をやめ、暦月ごとに 1 か月おきの薄い帯（`--bg` の半透明）を棒の下に敷く。帯は軸の下まで伸ばし、帯の下端に月と暦月の合計を書く。凡例は「帯は暦月 · 帯の下の数は暦月の合計」
- 狙い: どの週がどの月か、月の幅（4 週か 5 週か）が線より一目で分かる。合計は帯に属して読める
- 判断: 合計を帯の上端（棒の上）に書くと、最大の週の棒と 11px しか空かず重なるため、帯の下端に置いた。範囲の最初の端数の月（2025-09）は 00 と同じく帯も合計も出さない。帯に収まらない月名（2026-09（途中））は帯の右端に揃える
- 実装: `charts.js` は foot を棒の後に描くため、`twelve.js` の `behind()` で帯の群を svg の先頭へ移している（charts.js は変えていない）
- 懸念: 帯の有無が「その月に意味がある」ように見えうる。最後の月は右揃えのため、隣の月の文字と近い

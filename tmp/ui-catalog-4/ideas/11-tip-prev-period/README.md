# 11 ツールチップに前の期間

- 名前: ツールチップに前の期間（基準案 00 の写し。変えたのは `parts/spark-tip.js` だけ。ほかは 00 と同じ）
- 変えた点: 7 日・28 日のカード（送信した利用者・1 日あたりのセッション・コスト）の小さなグラフの札に、同じ位置の前の期間の値を並べる（「09/24（木）  $304.73 · 前 $202.80」）。前の期間の点（薄い側）は前が無いので値だけ。12 か月は前の期間を持たないので 00 と同じ
- 狙い: 折れ線の山と谷が前の期間より高いか低いかを、目で線を追わずに 1 か所で読める
- 懸念: 「前」の値も今の値と同じ濃さ・太さで出る（tip.js は区切りの後ろを 1 つの強調として組むため。変えるなら tip.js に手を入れる）。札が右隣のカード（見込み）に重なるのは 00 と同じ
- 画像: shot-tip-users / shot-tip-sessions / shot-tip-cost（7 日・直近の点）、shot-tip-older（前の期間の点）、shot-tip-28d（28 日のコスト）

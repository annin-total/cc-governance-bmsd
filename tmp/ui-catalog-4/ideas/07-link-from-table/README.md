# 07 連動を表の側から

- 名前: 連動を表の側から。00 を写し、`parts/link.js`（と `link.css` の見出しのコメント）だけを差し替えた。ほかは 00 と同じ（画像も変えた所の 2 枚だけ。ほかは 00 の画像を見る）
- 変えた点: 下段のタブの表の行に当てたときだけ、同じ日（週・営業日）の棒・点を強調し、ほかの棒を薄くする。グラフの棒に当てても何も変わらない。グラフから表への強調と、表の自動のスクロールはなくした
- 狙い: 動きを最小にする。グラフの上でマウスを動かしても画面が揺れず、表を読むときにだけ位置の手がかりが出る
- 懸念: グラフから値を知る手段がなくなる（タブのグラフにツールチップは出さない合意のため）。特定の棒の値は、表を探すか絞り込みで引く。今月のコストの累積の点も、表から当てないと前月の点・縦線が出ない
- 画像: `shot-link-row.png`（28 日・日ごとのコストで 09/25 の行に当てた）、`shot-link-bar.png`（同じタブで棒に当てても変わらない）

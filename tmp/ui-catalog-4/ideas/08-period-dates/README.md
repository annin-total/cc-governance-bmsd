# 08 期間の日付を添える

- 名前: 期間の日付を添える。00 を写し、`parts/period.js` と新しい `parts/period.css`（index.html・assets.html から読む）だけを変えた。ほかは 00 と同じ（画像も変えた所の 3 枚だけ。ほかは 00 の画像を見る）
- 変えた点: 見出しの右の分段の下に、選んだ期間の日付を小さく右揃えで 1 行。7 日「09/23〜09/29 · 前の 7 日 09/16〜09/22」、28 日「09/02〜09/29 · 前の 28 日 08/05〜09/01」、12 か月「2025-09-29〜2026-09-28」（前の期間と比べないので 1 つだけ）
- 狙い: 「7 日」「28 日」が具体的にどの日からどの日かを、群の見出しやカードを読まずに分かるようにする。行は見出しの説明文と同じ高さに揃い、ページの縦の位置は 3px しか動かない
- 仮の判断: 7 日・28 日は記録の期間（events_window）を出す。利用明細の期間は 1 日前で終わる（コストのカードの「09/01〜09/28 の合計」と 1 日ずれて並ぶ）。12 か月は利用明細の期間（`DATA_EXTRA.twelve`）で、群の見出しの書き方（ISO）に合わせた
- 懸念: 28 日で上の日付とコストのカードの日付が 1 日ずれて見える。12 か月は群の見出しの括弧と同じ日付が重なる

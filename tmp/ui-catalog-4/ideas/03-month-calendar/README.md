# 03 今月のタブを暦日で

- 変えた点: 今月のコストのタブの累積グラフの横軸を暦日（1〜31）にし、今月の週末と祝日を薄い帯（`--chip`）で敷く。凡例に「9 月の週末と祝日」。`parts/month-tab.js`・`month.css` だけを変更し、ほかは 00 と同じ
- 狙い: 「休日の分は次の営業日に含める」という読み替えをなくし、カレンダーと同じ感覚で読めるようにする
- 画像: `shot-forecast-tab.png`（タブを開いた全体）、`shot-detail-month.png`（グラフを 2 倍）、`shot-detail-month-hover.png`（日曜の 20 日に当てた連動）、`shot-link-row.png`（表の 09/14 に当てた連動）。ほかは 00 と同じ
- 判断: 連動の点と行を一致させるため、表も暦日の行にした（日付・営業日の番号（休みは —）・その日のコスト・累積・前月の同じ日付までの累積）。祝日は日付の後に名前。前月の線は同じ日付に重ねる（帯は今月の曜日だけ）。見込みの累積は残りの営業日（29・30 日）に置く。日ごとのコストは `DATA.daily_cost` から数え、合計は 00 の営業日の値と一致（9 月 $8,959.84・8 月 $11,120.44）
- 懸念: 表が 31 行になり、休日のコストが平日並みにあるこの seed では帯の意味が薄く見える。その日のコストの列は最大が 1,000 未満になり小数 2 桁で表示される（00 は休日を足した日があり整数）

# 12 単位を小さく薄く

- 名前: 単位を小さく薄く（基準案 00 の写し。変えたのは `common/fmt.js` の `usd`・`usdCol`・`tok`・`tokCol`・`withUnit` と `common/common.css`。ほかは 00 と同じ）
- 変えた点: 金額・トークン・件数などを「数字（`.n`）＋単位（`.unit`）」の部品にし（`.nv` で包む）、単位（$・k・M・人・件・回・行）を小さく薄く、数字を数字用の書体（`--fig`）の等幅にした。表の数値の列とカードの割合の行は、単位のない数字も同じ書体にそろえる。カードの大きな値の単位（人・件・%）も薄くした。文章の中（注記・凡例・カードの下の注）の単位は大きさと色を変えない
- 付随の変更: 札（ツールチップ）と取り込みの知らせは文字だけなので、文字の版 `Fmt.unitText` を足して `pages/overview-cards.js`（3 か所）と `parts/export.js`（1 か所）の呼び出しを差し替えた
- 狙い: 数字だけが目に入り、表の桁がそろう。00 との比較は shot-compare（上が 00、下が 12。概況の利用のカードと今月のタブの表）
- 懸念: 金額の $ が前に小さく付くのは好みが分かれる。`F.pct`（%）や、設定の適用状況・効果の base の写しに静的に書かれた数値（$7.12・60k–80k・33 人 など）は対象外なので、同じ画面で形が混ざる。カードの下の注で「前の 28 日 35 人」の人が小さくなる一方、「3,686 件 / 全 14,742 件」は文字のままで小さくならない
- 画像: shot-7d / shot-28d（概況）、shot-assets-28d（スキル・コマンド）、shot-effect（設定の効果）、shot-forecast-tab（今月のコスト）、shot-compare（00 との比較）

# 06 連動を押して固定

- 名前: 連動を押して固定。基準案 00 の写しで、`parts/link.js`・`parts/link.css` だけを変えた。ほかは 00 と同じ
- 変えた点: 下段のタブの棒・表の行を押すと強調を固定し、表の絞り込みの行（件数の左）に「09/23 を表示中 ×」の札を出す。同じ棒・行をもう一度押すか札を押すと外れる。別の棒・行を押すと固定がそこへ移る。固定中は当てても強調は変わらず、当てた棒だけを少し濃くして押せることを示す
- 狙い: 表を読み比べる間、強調した日が指を離しても消えない
- 判断: 札の文言は行の日付（12 か月は週の始まり、今月のタブの日付のない行は「20 営業日目」）。札は chipbar と同じ地（`--tabs`）。固定は画面を読み直すと消える（URL に残さない）
- 懸念: 当てた強調と固定した強調が同じ見た目のため、札を見ないと固定中か分からない。棒・行が押せることは指の形でしか示していない
- 画像: `shot-pin.png`（28 日の日ごとのコストで 09/23 を押して固定）、`shot-pin-other.png`（固定したまま 08/24 に当てた）、`shot-unpin.png`（札の × で外した）。ほかは 00 と同じ

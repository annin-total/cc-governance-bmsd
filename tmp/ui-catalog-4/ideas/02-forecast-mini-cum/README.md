# 02 見込みに極小の累積線

- 変えた点: 見込みのカードの 2 列の数字の下に、高さ 28px の累積の線（今月の実績・見込みの破線・前月の薄い線。横軸は営業日、縦は 0 から）。点に当てるとほかのカードと同じ札（「18 営業日目 · 09/29  見込み $9,487 · 8 月 $9,713」）。`parts/forecast-card.js`・`forecast.css` だけを変更し、ほかは 00 と同じ
- 狙い: 前月より上か下か、見込みへの伸び方を、タブを開かずにカードで掴めるようにする
- 画像: `shot-7d.png`（全体）、`shot-detail.png`（カードを 2 倍で拡大）、`shot-detail-hover.png`（札）。ほかの画面・状態は 00 と同じ
- 判断: 線と札の見た目は他のカードの小さな折れ線（`spark-*`・tip.js）に揃えた。縦軸は累積なので 0 から
- 懸念: 「利用」の行が 19px 高くなり、隣のカードの折れ線が下がる。28px では今月と前月の差が小さく見え、破線も読みにくい（下段のタブと役割が重なる）

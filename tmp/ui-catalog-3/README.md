# 管理画面デザイン・カタログ 第 3 弾

期間の切り替え・月末のコストの見込み・数値の表示とツールチップ・エクスポートのページを、今の管理画面に足す案を 14 個並べたもの。**一時的な文書で、案が決まったら消す。**

- 土台は本物の画面の写し（`base/`）。値はダミーデータ（40 人・400 日）を今のサーバで集計したもの（`data/`）。指示書は `brief.md`
- 各案は `ideas/NN-*/index.html`（概況）と `export.html`。file:// で開ける。焦点以外は既定の扱い（見出しの右の分段・「利用」の群の見込みカード・浮いた札のツールチップ・素朴なフォーム）

| No | 名前 | 焦点 | 骨子 |
| --- | --- | --- | --- |
| 01 | 素直な追加 | 全体 | すべて既定の扱い。基準線 |
| 02 | 見出しが切り替えになる | 切り替え | 群の見出しの期間の文言の中の日数を分段に |
| 03 | 固定の期間バー | 切り替え | ナビの下の固定の帯に、切り替え・具体的な日付・CSV の最終日 |

## 全案に共通の仮置き（実装で決め直す）

- 見込みを「—」にする閾値は経過 3 営業日未満
- 12 か月の利用者数は直近の完全な週の人数（重複を除いた 12 か月の人数はデータに無い）
- 28 日でも「項目の欠け」と一部のタブの中身は 7 日の値のまま（カタログ用のデータに 28 日の明細が無いため）
- 描画は JS（window.DATA）。本実装はサーバで描き、切り替えは URL での再読み込みにする
- ファイル選択の「Choose File」はヘッドレスのブラウザの表示で、実機では日本語になる

## 今の画面の不具合（案とは別）

概況の「日ごとのコスト」のグラフは CSV の全期間を描き、目盛りを 7 本ごとに付けるので、CSV が 4 か月分ほど溜まると目盛りの文字が重なる。期間の切り替えの実装で直す。

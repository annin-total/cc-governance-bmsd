# 07 十字線と値の読み取り
- 焦点: ツールチップ。浮いた札を出さず、当てた日に縦の線を引き、カード見出しの右（「一覧 ↓」の位置）をその日の値に置き換える
- 狙い: 同じ群のカードは日付で連動し、1 か所に当てると全カードが同じ日の値を出す。CSV に無い日（09/29 のコスト）は「—」で線を消す。タブの棒グラフは縦線の代わりに列の帯を敷き、グラフの見出しの右に値を出す（値のラベルと線が重なるため）
- 部品: 新規は十字線（点線 1 本）・列の帯・見出しの読み取り表示。既存の .go の位置と .p-chart h3 を再利用し、札の部品は要らない
- 工数感: 小〜中。JS 1 本（約 80 行）。カード見出しは省略記号で切り、読み取り中も高さが変わらないようにした
- 懸念: カードの読み取りは幅が狭いので曜日を省いた。当てている間は「一覧 ↓」が消える。値が見出しに出ることに気づかれにくい。日付の刻みが違う 12 か月では週単位で連動する
- 仮置き: 下段は「日ごとの利用」だけ期間に追従（他のタブは 7 日のまま）。「項目の欠け」は期間別の値が無く 7 日の値を流用。12 か月の利用者は直近の完全な週の値。見込みを「—」にする閾値は仮に経過 3 営業日未満
- 画像: shot-7d / 28d / 12m / tip（カード中ほど）/ tip-edge（最終日。コストは —）/ tip-2（タブの棒）/ tip-12m / export

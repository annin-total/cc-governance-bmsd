# 12 取り込むと書き出すの 2 列
- **焦点**: エクスポート。ページを左右 2 列（取り込む｜書き出す）に分け、書き出す側は月を選ぶと 4 表の行数・大きさ・列の一覧が見える
- **狙い**: 手元の Python で読む前に「何が何行、どの列で来るか」を分かったうえで落とせる。取込と書き出しが同じ画面で対になる
- **部品**: 新規は 2 列の格子・月の select・表の一覧（列名は等幅の小さな文字で折り返す）。既存の `.panel`・`.glabel`・`.tscroll` の表・`.btn`・`.notice ok` を再利用
- **既定の扱い**: 概況（index.html）は期間の分段・見込みのカード・ツールチップ・ヘッダー右端の入口を既定どおりに載せた（案 13 と共通）
- **工数感**: 小〜中。月ごとの行数・大きさの集計 API（見込みで可）と ZIP の生成が要る。画面は select 1 つとサーバ描画の表で足りる
- **仮の値**: 取込の結果の文言（「3 ファイルを読み」）と最後に取り込んだ時刻は仮。大きさは data.js の見込み値
- **懸念**: 列の一覧は情報が多く、右の列が縦に長い。月を選ぶ前は行数と大きさが「—」で、ボタンが押せない（1 手余計）
- 画像: shot-7d / 28d / 12m / tip、shot-export（初期）/ shot-export-month（8 月を選んだ）/ shot-export-import（取込の後）

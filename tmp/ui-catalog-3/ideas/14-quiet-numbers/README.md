# 14 数値の静かな表示
- **焦点**: 数値。単位（$・k・M・%・人・件・回・行）を小さく薄くし、数字は数字用の書体（--fig）の等幅の字形で右にそろえる。丸めた値（1,000 以上の金額・トークン）は当てると正確な値を札で出す
- **狙い**: 数字だけが目に入り、桁がそろう。丸めによる情報の欠けをツールチップで補い、表示は短く保つ
- **部品**: 新規は数値の部品（`.nv` = `.unit.pre` + `.n` + `.unit`）と、サーバが描いた数値に同じ形を当てる quiet.js。既存の指標カード・表・ツールチップ（既定の札）を再利用
- **トークン**: カードは 100 万未満を k（981k）、以上を M（1.2M）。表の列は最大値で単位を 1 つに決め、列の中で混ぜない（1 人あたりトークンは M・小数 2 桁）
- **工数感**: 中。書式をサーバの 1 か所（filters）に寄せ、`data-tip` に正確な値を持たせる。全画面の数値のセルに効くため、テストの文字列の検査の見直しが要る
- **仮の値**: 12 か月の週ごとの表は、列に 1,000 以上があるので全行を整数にそろえた。スキル・コマンドの 12 か月は記録由来のため群ごと出さない
- **懸念**: 範囲の値（60k–80k）は k が小さくなり途切れて見える。大きな数字の前の小さな $ は好みが分かれる。当てられる値は当てたときだけ点線の下線が出るので、気づきにくい

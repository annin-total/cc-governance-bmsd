# 03 固定の期間バー（焦点: 切り替え）

- 狙い: ナビの下に細い帯（40px、sticky）を常設し、分段・具体的な日付（直近 09/23〜09/29 · 前の 09/16〜09/22）・「利用明細は 09/28 まで」を 1 行に。下の表を見ていても期間が見える（shot-sticky.png）
- 部品: 新規＝期間の帯（地は --bg・下に罫）。見出し右は空く。ほかは 01 と同じ
- 共通（01〜04 同じ）: 見込みは「利用」の 4 枚目（前月と今月の 2 本の棒。今月は実績＋見込みの残りを薄く）。「確認なし」は 2 行目に回る。12 か月は CSV 由来の 3 枚だけ・届き具合は見出しの 1 行・タブは週ごとの 2 つ。浮いた札は --card 地・細い罫。エクスポートは月の select＋ZIP ボタン＋取込
- 仮に置いたもの: 12 か月の利用者＝直近の完全な週の人数（12 か月の重複なし人数が data に無い）。見込みを「—」にする閾値＝経過 3 営業日未満。$ は 1,000 以上で整数・表は合計の最大で全列の桁をそろえる。使われ方・受信と欠け・エラーのタブの中身は base の 7 日のまま（28 日の集計が data に無い）。欠けのカードも 7 日の値
- 描画は JS（window.DATA → HTML）。本実装はサーバ描画なので、切り替えは ?period= のリンクで再読込に置き換える想定
- 工数感: 小〜中（帯を出すのは概況とスキル・コマンドの 2 画面だけ）
- 懸念: 上段が約 40px 下がり、1440×900 で届き具合の群の下端が 885px と余裕がない。ヘッダーの罫と帯の罫で線が 2 本並ぶ。群の見出しの期間の文言と内容が重なる

# 08 グラフと表の連動
- 焦点: ツールチップ。タブのグラフの棒に当てると表の同じ行を強調して表の枠の中で見える位置までスクロールし、行に当てると両グラフの同じ日の棒を強調する（他の棒を薄くする）
- 狙い: 値は表の行で読むので、タブのグラフには札を出さない。カードの折れ線は既定の札。「日ごとのコスト」タブ（399 日の細い棒）も連動させ、当てた日に点線を引く
- 部品: 新規は行の強調（地を --tabs、左に強調色の縦線）と、棒の強調（他を薄く）。既存の表・棒グラフ・絞り込みをそのまま使う
- 工数感: 小〜中。行と棒に日付の data 属性を付け、JS で相互に引くだけ。サーバの描画は変えない
- 懸念: 行が表の枠の外なら枠の中をスクロールするので、表が動いて見える。絞り込みで隠れた行は強調しない。今の「日ごとのコスト」のグラフは週ごとの目盛りが重なっているので、この案では各月の最初の目盛りだけ残した（今の画面の課題）
- 仮置き: 下段は「日ごとの利用」だけ期間に追従（他のタブは 7 日のまま）。「項目の欠け」は期間別の値が無く 7 日の値を流用。12 か月の利用者は直近の完全な週の値。見込みを「—」にする閾値は仮に経過 3 営業日未満
- 画像: shot-7d / 28d / 12m / tip（カードの札）/ tip-2（棒 → 行）/ tip-3（行 → 棒）/ tip-4（日ごとのコスト）/ export

# 06 見込みの累積グラフ
- 焦点: 見込み。見込みのカードを 2 枠幅にし、今月の累積（実線）・月末までの見込み（破線）・前月の累積（薄い線）を描く
- 判断: 横軸は営業日にした。見込みの式（実績 × 営業日 ÷ 経過営業日）と一致して破線が直線になり、月ごとに営業日数が違っても前月と並べられる。休日の分は次の営業日に含めた
- 部品: 新規は累積グラフ（SVG 3 本・目盛り・線の凡例）と 2 枠幅カードの内部の 2 列配置。既存の .card.wide・.change・.cap・.legend・既定の札を再利用
- 工数感: 中。月ごとの営業日の累積を集計側で作る必要がある（前月の営業日の一覧もいる）
- 懸念: 利用の群が 2 行になり上段が詰まる（1440×900 にぎりぎり収まる）。暦日に慣れた人には「17」が日付に見える恐れがあり、「横軸は営業日」の注記に頼っている
- 仮置き: 下段は「日ごとの利用」だけ期間に追従（他のタブは 7 日のまま）。「項目の欠け」は期間別の値が無く 7 日の値を流用。12 か月の利用者は直近の完全な週の値。見込みを「—」にする閾値は仮に経過 3 営業日未満
- 画像: shot-7d / 28d / 12m / tip（カードの折れ線）/ tip-2（累積グラフ）/ forecast / export

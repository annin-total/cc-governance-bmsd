# 11 月の一覧からダウンロード
- 焦点: エクスポート。月の一覧表の各行にダウンロードのボタン。選ぶ操作なしで押すだけ。取り込みはページの上部
- 狙い: どの月がどれくらいの量かを見比べてから、欲しい月を 1 回で取れる
- 部品（新規）: 行の中の控えめなボタン（地は --chip）、ファイル選択の見た目
- 部品（再利用）: 群の見出し・パネル・並べ替えつきの表（4 表の行数・大きさ・棒）・注記
- 工数感: 小〜中。月ごとの行数の集計（数える SQL）と ZIP の書き出し。大きさは実測でなく見込みでよい
- 懸念: 14 個のボタンが並ぶ。月が増えると表が伸びる（年で畳むかは未定）。大きさは 2026-08 の圧縮率からの見積もり
- ほかの部分: 既定の扱い。12 か月は案 10 と同じ扱い（空の札）を借りた。スキル・コマンドの利用のページは作っていない（ナビは base へ）
- 模型の制約: ファイル選択の「No file chosen」はブラウザの言語の文字（日本語の環境では日本語になる）

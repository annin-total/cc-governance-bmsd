# 13 月の格子
- **焦点**: エクスポート。暦年の 12 か月をカレンダー風の 4×3 に並べ、各マスに行数・ZIP の大きさ・行数の相対の細い棒。押すとその月の ZIP をダウンロード
- **狙い**: 選ぶ操作なしで 1 回押すだけ。月ごとの量の増え方も格子で一目に分かる。年は右上の分段（2025 年・2026 年）で切り替え
- **部品**: 新規は月のマス（カードと同じ地・角丸・選んだマスは `.is-open` と同じ枠）。既存の `.chipbar`・`.hbar`・`.notice ok`・`.panel`・ツールチップ（マスに当てると 4 表の内訳）を再利用
- **既定の扱い**: 概況（index.html）は期間の分段・見込みのカード・ツールチップ・ヘッダー右端の入口（案 12 と共通）。取込は格子の下に 1 行
- **工数感**: 小。月ごとの行数・大きさ（見込み）を返せば、格子は 12 マスの定義から描ける
- **仮の値**: 最初の月（2025-08）は「08/26 から」、今月は「途中」の札。取込の結果の文言と時刻は仮。大きさは data.js の見込み値
- **懸念**: データの無い月の空のマスが多い年（2025 年は 7 マス）は寂しく見える。押すとすぐ落ちるので、中身（表と列）は押す前にはツールチップでしか分からない
- 画像: shot-7d / 28d / 12m / tip、shot-export（初期）/ shot-export-month（8 月を押した）/ shot-export-2025 / shot-export-import（取込の後）

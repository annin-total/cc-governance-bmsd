# 05 今月の帯
- 焦点: 見込み。概況の最上部（群の上）に全幅の「今月のコスト」の帯を置き、見込み・実績・営業日の進み・営業日あたりの前月比・前月の合計を 1 行に並べる
- 狙い: 会社のコスト概算に使う数字を、期間の切り替えと切り離して常に最初に見せる。群の見出しに「暦月で数え、期間の切り替えとは別」と書く
- 部品: 新規は帯（.mband・区切り罫つきの 5 区画）と営業日の刻み棒（.segs、1 営業日 = 1 区画）。既存の .card の地・.k-value・.change・.glabel を再利用
- 工数感: 小。サーバは見込みの値を 1 つの辞書で渡し、テンプレートに区画を並べるだけ
- 懸念: 帯の分だけ上段が約 180px 伸びる（1440×900 には収まる）。期間の切り替えが帯の上にあるため、帯も切り替わると誤読される余地がある
- 仮置き: 下段は「日ごとの利用」だけ期間に追従（他のタブは 7 日のまま）。「項目の欠け」は期間別の値が無く 7 日の値を流用。12 か月の利用者は直近の完全な週の値。見込みを「—」にする閾値は仮に経過 3 営業日未満
- 画像: shot-7d / 28d / 12m / tip / band / export

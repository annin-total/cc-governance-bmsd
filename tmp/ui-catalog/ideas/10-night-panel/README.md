# 10 夜の計器 — 概況（/）

- 狙い: 常時表示の監視画面として、暗い地に落ち着いた青と状態の灯（正常・注意・要確認）だけを置き、離れて見ても異常の有無が分かるようにする。
  明るい表示との切り替え付きで、ダークモードを入れるときの姿を示す。
- 情報の組み立て: データの届き具合（記録・利用者・照合率・プラグインの版の 4 計器 → エラーの表・項目の欠け）→ 利用とコスト（日ごとのコスト積み上げ、利用者数とセッション数）→ 使われ方（3 つの分布）
- 色と文字: 濃紺の地 #0c121a・パネル #121a25、アクセント #8db4e2、状態色 3 つ＋中立。数字は等幅（SF Mono / Menlo）、文字はヒラギノ角ゴ。明るい表示は同じ変数を差し替え
- UI 部品: 状態の灯つき計器、前後比較の細い棒、版の積み上げ棒、欠けの割合のダンベル図（しきい値の帯つき）、積み上げ棒グラフ、折れ線、畳んだ明細表、表示切り替えのボタン（localStorage で記憶）
- 工数感: 中〜大。CSS 変数で配色を 2 組持つのは小さいが、SVG グラフ 4 種と、状態の判定基準（エラー・記録数の減少）の取り決めが要る
- 懸念: エラーは 1 件でも「注意」、記録・利用者は前の週の 8 割未満で「注意」、照合率は 95% 未満で「注意」とした。いずれも仮の基準。プラグインの版は /policy から移してここに 1 か所だけ置いた

# 07 少ないインクのグラフ（設定の効果）

- **狙い**: Tufte 流に枠・塗り・凡例・目盛り線を削り、データの点と線だけで「守る前と後で何が変わったか」を読ませる。結論は冒頭の 1 段落に数字を埋めて書き、注意書きは欄外（右の注）に置いて図の読みを邪魔しない。
- **情報の組み立て**: 結論の段落 → 3 指標（コスト・トークン・対象者数）の表。各行に前後の平均と 28 日のスパークライン → 1 人あたりコストの点グラフ（前後の平均線、値域だけの縦軸） → 圧縮直前・応答終了のスモールマルチプル（前後を割合に直して区間をそろえ、同じ縦軸で重ねる。中央値の区間を ▲）。今の 28 行と 4 つの分布表は図に置き換える。
- **色と文字**: 生成りの地に墨、色は藍 1 色（守った後）だけ。守る前は灰。本文と見出しは明朝、図の文字・注・数字の補足はゴシック。凡例を置かず、線の脇に直接ラベル。
- **UI 部品**: 行内スパークライン、点グラフ、段階状の分布線のスモールマルチプル、欄外注。操作部品は無し（点に hover で値）。
- **工数感**: 中。SVG の描画を JS で 150 行程度。分布の区間をそろえる（0 件の区間を 0 で補う）処理と割合への変換が要る。サーバ側の集計は今のままで足りる。
- **懸念**: 数値の一覧（28 日ぶんの値）が画面から消えるので、正確な値を見たい人には表を畳んで添える必要がある。冒頭の結論文は値から自動で作っており、データの形が変わると文が不自然になりうる。分布は割合なので件数の差（600 件 → 1,038 件）は下の注でしか読めない。

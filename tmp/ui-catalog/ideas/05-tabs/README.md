# 05 タブで切り替える（概況）

- **狙い**: 問いの種類が違う 3 つのまとまり（データの届き具合 / 利用 / 費用）を分段タブで分け、1 度に 1 つだけ見せて縦の長さと迷いを減らす。タブの横に要点（エラー件数・今日の人数・直近 7 日の費用）を出し、開かずに当たりを付けられる。
- **情報の組み立て**: 届き具合 = 受信 3 指標 → エラー → 項目の欠け。利用 = 日ごとの人数・セッション（14 行＋行内の棒）→ 使い方の内訳 3 表を横並び。費用 = CSV 取り込み（操作）→ 提供元別の 7 日比較 → 全期間の積み上げ棒グラフ（143 行の表は日×提供元の 73 行に組み替えて畳む）。プラグインのバージョンは概況から外し、設定の適用状況の 1 か所に寄せる前提。
- **色と文字**: 地は薄いグレー、節は白い面。アクセントは藍 1 色（#23466b）、2 系列目はその淡色。状態色は ok/warn/ng の 3 つのみ。ゴシック 1 系統、数字は tabular-nums・右揃え。
- **UI 部品**: 分段タブ（role=tablist、←→ キー、URL の #health / #usage / #cost で保持）、指標の横並び、行内の棒、積み上げ棒 SVG、details。
- **工数感**: 小〜中。タブは JS 20 行程度でテンプレートの節を 3 つの panel に包むだけ。費用の提供元別 7 日集計と日×提供元のピボットはサーバ側に集計を 1 つ足す。
- **懸念**: タブの中身は印刷・ページ内検索（Ctrl+F）で見つからない。費用タブの「直近 7 日」は CSV の最終日基準で、他タブの直近 7 日と終わりの日がずれる（見出し下に明記して対処）。

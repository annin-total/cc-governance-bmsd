# 13 施策の効果に集中（設定の効果）

- 狙い: 「設定は働いているか」と「コストは下がったか」を分けて答え、前者（コンテキストの分布）を主役に、後者（時期の変動を含むコスト差）を灰色に下げる。解釈の注意は図の横の欄に置く。
- 組み立て: 冒頭の 2 文の答え → 図 1 スロープグラフ 4 枚（12 万トークン以上の割合 2 つ＝青、1 人あたりコスト・トークン＝灰）→ 図 2 前後を重ねたヒストグラム（割合で正規化、12 万の破線）→ 図 3 日ごとの推移（0 日目を空け、対象者数の帯）。表は details に畳む。
- 色と文字: 白地、適用前 = 暖灰 #8a8178（輪郭）、適用後 = 藍 #1f4f7a（塗り）、注意だけ茶 #92560a。見出しは明朝、本文と数字は sans の tabular-nums。
- UI 部品: スロープグラフ、重ねヒストグラム（段の輪郭＋棒）、点付き折れ線と平均の破線、欄外注記、details。
- 工数: 中。集計は既存データから前端で計算できる（前後の加重平均・12 万以上の割合）。
- 懸念: 「12 万トークン = 60%」は上限 20 万トークンのモデルを仮定した推定。モデルの上限が混在すると線の意味がずれる。コストの前後平均は対象者数で重み付けした値で、サーバの定義ではない。

# 01 帳簿

- 狙い: 今の概況の節の順と中身はそのままに、文言と文字の階層だけで読みやすくする。「最小の変更で最大の洗練」の基準線になる案
- 情報の組み立て: 各節を「左に見出し欄（明朝の見出し・期間と母集団・薄い説明）｜右に表」の 2 段に固定。受信のタイルは 1 枚の表に、日ごとのコストは日 × 提供元の横持ちに直して新しい 14 日だけ出し、残り 59 日は畳む
- 色と文字: 生成りの地 #f8f5ec・墨 #26231f・紺 #1f3a5f の 1 色。見出しだけ明朝、本文 13px のゴシック、数字は tabular-nums で右揃え。罫線は細い横線だけ
- UI 部品: 表、details（畳み）、状態の点（正常/注意/要確認）、ボタン 1 つ
- 工数: 小。テンプレートの文言・CSS の差し替えと、日ごとのコストの横持ち化（SQL か Jinja の集計）だけで済む
- 懸念: 構成を変えないので「何を先に見るか」は解決しない。プラグインのバージョンは概況に残し、/policy 側から外す前提

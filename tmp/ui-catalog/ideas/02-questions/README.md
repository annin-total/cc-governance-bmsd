# 02 問いで並べる

- 狙い: 画面の区切りを「使われているか／守られているか／効果はあるか／データは正常か」の 4 問にし、問いの直下に答えの数字を 1 つだけ大きく置く。根拠の表とグラフは下に小さく
- 情報の組み立て: 4 画面の材料を 1 ページに再配置（上部ナビは問いへのアンカー）。問い 3 の答えは「12 万トークン以上で圧縮された記録の割合 38.0% → 0.0%」を分布から算出。コストの前後差は注意書き付きの補助図に下げた
- 色と文字: 冷たい白の地 #f3f4f1・墨・藍 #34508a の 1 色。問いは 34px の太いゴシック＋藍の「？」、答えは 96px の細身の数字書体（Avenir Next Condensed）
- UI 部品: 大きな数字、インライン SVG（棒・ヒストグラム・前後の折れ線）、小さな表、横棒
- 工数: 中〜大。画面の統合とルーティングの変更、答えの数字の選び方（何を 1 つに絞るか）の仕様決めが要る
- 懸念: 「答えの 1 つ」の選定が恣意的になりやすい（問い 2 は最も低い適用率を採用）。12 万トークンの線はしきい値 60% と文脈窓 20 万の仮定に依存

# 04 指標カードと小さな推移

- 狙い: 上段の 6 枚のカード（数字・前の 7 日との差・小さな推移）で全体を一目で掴み、押すと該当の詳細へ移る
- 情報の組み立て: カードは「利用」（利用者・1 日あたりのセッション・コスト）と「データの届き具合」（記録・照合率・エラー）の 2 群。下に詳細のパネル 5 枚（推移の棒、日ごとのコストの積み上げ棒 73 日、受信と欠け、エラーとバージョン、使われ方）
- 色と文字: グレージュの地 #e8e5e0・カード #f6f4f0・スレート #4c6a78。エラーだけ茶系の注意色。数字は Avenir Next の 40px
- UI 部品: カード（アンカーリンク）、スパークライン（直近 7 日を塗り分け）、比較の横棒、メーター、積み上げ帯、SVG の棒グラフ、details
- 工数: 中。カードの差分計算とスパークライン用の日次系列（記録数の日次は今のデータに無い）を追加する必要がある
- 懸念: 受信した記録には日次の系列が無いので推移を出せず、前後 2 本の棒で代用した。「1 日あたりのセッション」は新しく作った指標

# 03 要約文から入る

- 狙い: 最上部で、数字を埋め込んだ 4 文の平文が「今どうなっているか」を答える。表を読まなくても状況が伝わる
- 情報の組み立て: 要約（利用・コスト・エラー・欠けと照合の 4 文）→ 詳細の表 7 つを details で畳んで並べる。要約中の下線付きの数字を押すと、根拠の詳細が開いて強調される。CSV 取り込みは操作なので最後に分けた
- 色と文字: 薄いグレーの地 #f5f6f7・白の面・深緑 #1d5c50 の 1 色。要約は 22px、数字は太字の深緑に下線。詳細の見出しは 15px、期間と母集団は 12px の薄色
- UI 部品: 要約リスト（話題ラベル付き）、details、すべて開く/閉じる、表内の横棒、スクロール枠（日ごとのコスト 73 日）
- 工数: 中。文の組み立て（条件で言い回しを変える: 増えた/減った、全員/一部）をサーバ側で持つ必要がある
- 懸念: 文の雛形が増えると保守が重い。値の変化に応じた言い回しの分岐を誤ると、平文だけに誤読を招く

# 12 一覧と詳細の分割（概況）

- 狙い: 概況の 10 指標を左に「名前・現在値・状態の点」だけで並べ、1 度に 1 つの指標だけを右で深く見せる。縦に長い表（日別コスト 143 行など）を画面から消す。
- 組み立て: 左 = 「データの届き具合」5 / 「利用の実態」5 の 2 群＋下端に CSV 取り込み。右 = 問い 1 行 → 期間・数え方 → 大きな値と前期間比 → グラフ → 内訳表 → 説明。選択は URL の # に保持、↑↓ キーで移動。
- 色と文字: 白地＋左の薄い灰緑、アクセントは深緑 #1d5c57 の 1 色（前期間は同系の淡色）。状態色は点と札だけ。数字は tabular-nums、見出しは sans の太字。
- UI 部品: listbox 風の指標リスト、横棒、1 人 = 1 点の点グラフ、ダンベル（前→今）、積み上げ棒（日×提供元）、小さな折れ線、表。すべてインライン SVG。
- 工数: 中。指標ごとに詳細の組み立てが違い、定義（metrics.js）の保守が要る。サーバ側は既存の集計のままで足りる。
- 懸念: 全体を 1 目で見渡せない（異常を見落とす）。左の状態の点で補うが、判定規則が無い指標（コスト・分布）は「判定なし」。プラグインのバージョンは「設定の適用状況」に一本化する前提で外した。受信した記録の日別推移はサーバに無く、前後 2 本の棒だけ。

# 06 左の目次と絞り込み（設定の適用状況）

- **狙い**: 4 画面の節を「使われているか／守られているか／効果はあるか／データは正常か」の問いの木にまとめて左に常に出し、どこに何があるかを 1 か所で分かるようにする。画面の中では、絞り込みと並べ替えで「誰の・どの端末を直すか」にすぐ辿り着く。
- **情報の組み立て**: 適用率（6 設定・分子 / 分母・棒・未適用の台数）→ 端末ごとの状況 → バージョン（プラグインと本体を横並び）。今の「端末ごとの現在の値」「未適用 ×6」「未導入」「報告停止」の 9 表を、状態の列を持つ 1 表（端末 44 台＋未導入 4 人）に統合。プラグインのバージョンはこの画面だけに置く。
- **色と文字**: 地は白に近い生成りグレー、目次は一段濃い面。アクセントは深い緑 1 色。状態色は ok/warn/ng（未適用・未導入 = ng、報告停止 = warn）。メールアドレス・端末名・設定キーは等幅、数字は tabular-nums・右揃え。
- **UI 部品**: 固定の目次（details で畳める・スクロール位置を追って現在の節を強調）、固定の絞り込みバー（利用者名の文字入力・最終報告の期間の分段ボタン・「要対応のみ」チェック・表示件数）、列見出しの並べ替え（aria-sort）、状態のバッジと行頭の赤線。
- **工数感**: 中。絞り込み・並べ替えはクライアント JS で済むが、9 表の統合はサーバ側で端末単位に結合し直す必要がある。目次は全画面のテンプレートに共通部品として入れる。
- **懸念**: 絞り込みが効くのは「端末ごとの状況」だけで、適用率は利用者単位のまま（見出し下に明記）。未導入の行は期間の基準（CSV の 30 日）が他の行と違い、「14 日以上前」などの期間の絞り込みでは消える。目次の幅 272px の分、表の横幅が減る。

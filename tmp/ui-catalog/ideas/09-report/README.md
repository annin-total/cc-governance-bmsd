# 09 報告書（紙面） — 設定の効果（/effect）

- 狙い: 分析の画面を、結論から読む報告書として組む。要旨で答えを先に言い、図・表・欄外の注で根拠と読み方の注意を添える。
  問いへの直接の答え（コンテキストの分布）を 1・2 節に、効果と読めないコストの比較を 3 節に回した。
- 情報の組み立て: 表題と書誌（設定・期間・提供元・集計日）→ 要旨（数字入りの 2 文）→ 1 圧縮直前の分布 → 2 応答終了時の分布 → 3 1 人あたりコスト。各節は 2 段組の本文・図・表と、右の欄外注
- 色と文字: 白に近い紙と机のグレー、墨の文字、深緑 1 色（適用後の系列と図番号）。見出し・図番号は明朝、本文と表はゴシック、数字は tabular-nums
- UI 部品: 図（SVG の対のヒストグラム、前後で分けた折れ線 2 段）、図表番号とキャプション、罫線だけの表、欄外注（番号付き）、印刷用 CSS
- 工数感: 中。SVG の図 3 つとテンプレートの組み直し。要旨の文は数字から組む簡単なロジックが要る（文言の条件分岐を増やすと大）
- 懸念: 「12 万 = 上限 20 万の 60%」は仮定（欄外に明記）。要旨の文は今のデータの形に合わせた書き方で、分布の形が変わると言い回しが合わなくなる

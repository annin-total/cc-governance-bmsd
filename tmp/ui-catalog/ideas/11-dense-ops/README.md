# 11 高密度の運用画面 — 設定の適用状況（/policy）

- 狙い: 12px 基調・3 列の格子で、適用率から例外の一覧までを 1 画面（1440×900）にスクロールなしで収める。長い表は枠の中だけでスクロールする。
  各表に絞り込み入力と列見出しでの並べ替えを付け、運用者が「誰の・どの端末か」をすぐ引けるようにする。
- 情報の組み立て: 左 = 設定ごとの適用率（未適用の人数と台数つき）・未導入の利用者・報告が止まった端末／中 = 未適用の端末（6 設定を 1 表に統合し、設定の選択で絞る）／右 = 端末ごとの現在の値・バージョン（プラグインと本体）
- 色と文字: 薄いグレーの地、白いパネル、濃い上部バー、紺 1 色のアクセント。状態は行頭の細い色の線（赤 = 未適用・未導入、黄 = 報告停止）。数字・端末名・日付は等幅
- UI 部品: 並べ替え可能な表（aria-sort）、絞り込み入力・選択、件数表示（絞り込み後 / 全体）、固定の列見出し、行内の小さな率の棒
- 工数感: 中。表の部品 1 つ（table.js 約 70 行）を全表で使い回せる。サーバ側の変更は不要（未適用の一覧を統合するだけ）
- 懸念: 利用者は共通のドメイン（@example.com）を省いて表示した。配布値は glossary の説明から写した値でデータには無い。画面の縦が 640px 未満だと各列が縦にスクロールする

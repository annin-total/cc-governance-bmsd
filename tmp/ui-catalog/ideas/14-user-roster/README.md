# 14 利用者の一覧を軸に（設定の適用状況）

- 狙い: 施策画面の節（適用率・未適用 6 表・未導入・報告停止・現在の値）を「利用者 1 行」の 1 枚の表に畳み込む。列見出しに設定ごとの適用率、セルに点、行を開くと端末ごとの内訳。
- 組み立て: 要約 1 文 → 状態の絞り込み（件数付き）と文字の絞り込み → 表（状態 / 利用者 / 端末数 / 設定 6 列 / 最終報告日 / 版）→ 注記 → バージョンの分布（この画面に一本化）。並びは未適用 → 未導入 → 報告停止 → すべて適用。
- 色と文字: 白地、アクセントは紺 #243b5a。●＝適用、赤の○＝未適用、—＝報告なし。状態札は ng/warn/neutral/ok の 4 色。端末名は等幅。
- UI 部品: 分段の絞り込み、検索、開閉する行（Enter/Space 対応）、同じ列に揃えた端末の子行、列見出しの小さな率の棒。
- 工数: 中。表示は既存データで組めるが、「版」列を埋めるには端末ごとの最新バージョンを返す集計をサーバに足す必要がある（今は分布しかないため空欄）。
- 懸念: 40 人を超えると縦に長い（既定で「すべて適用」を畳む等が要る）。報告停止の人も最後の値で「適用」と数えるサーバの定義をそのまま見せている。

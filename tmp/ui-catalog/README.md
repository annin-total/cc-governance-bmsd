# 管理画面デザイン・カタログ

管理画面を全面的にデザインし直すための案を 14 個並べたもの。**一時的な文書で、実装する案が決まったら消す。**

- 各案は静的な HTML 1 ページ（`ideas/NN-*/index.html`。file:// で開ける）。値はダミーデータ（`scripts/seed_dashboard.py`、40 人・74 日）を今のサーバで描画したときの実際の値（`data/context.json`）
- 作り込んだのは各案の 1 画面だけ。ナビの他の画面は飾り
- 今の画面: `current/*.png`、言い換え表: `data/glossary.md`、節と問い: `data/sections.md`、指示書: `brief.md`

## 第 2 弾（`ideas-2/`）

第 1 弾の評価（04 の見た目と 1 ページの要点、05 のタブ、06・14 の絞り込みと状態の区分）を受けた変奏。指示書は `brief-2.md`。
全案で「上段 = 要点のカード、下段 = 詳しい一覧（タブ＋絞り込み）」、カード・タブ・列は定義の配列から描画。各案で概況と設定の適用状況の 2 画面を作った。

| No | 名前 | 骨子 |
| --- | --- | --- |
| 01 | 04＋05 の素直な合成 | 上段にカード、下段にタブ。カードを押すと該当タブが区分つきで開く。基準線 |
| 02 | カードがタブを兼ねる | カードを押すと下の一覧が切り替わる。タブの帯なし |
| 03 | 要点と詳細を別ページに | 要点ページと詳細ページ（タブ＋一覧）を URL で分ける |

| 05 | 状態で束ねる | カードを要対応・注意・正常の束に自動で振り分け、正常は小さく |

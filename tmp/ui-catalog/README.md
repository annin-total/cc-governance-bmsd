# 管理画面デザイン・カタログ

管理画面を全面的にデザインし直すための案を 14 個並べたもの。**一時的な文書で、実装する案が決まったら消す。**

- 各案は静的な HTML 1 ページ（`ideas/NN-*/index.html`。file:// で開ける）。値はダミーデータ（`scripts/seed_dashboard.py`、40 人・74 日）を今のサーバで描画したときの実際の値（`data/context.json`）
- 作り込んだのは各案の 1 画面だけ。ナビの他の画面は飾り
- 今の画面: `current/*.png`、言い換え表: `data/glossary.md`、節と問い: `data/sections.md`、指示書: `brief.md`

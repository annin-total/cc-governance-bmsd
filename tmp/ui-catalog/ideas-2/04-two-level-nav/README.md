# 04 2 段のナビ

- 狙い: 上の段 = 画面、下の段 = 画面の中の一覧（タブ）を常設し、下の段はスクロールしても上端に残す。06 の目次の責務分離を横方向で
- 受け継いだもの: 04（配色・カード）、05（タブ）、06（目次による責務の分離・絞り込み）、14（区分チップ・利用者 1 人 1 行の表）
- 部品: 指標カード（通常・小）／小さな推移／横棒／状態の印／前との差／下の段のナビ（タブ）／絞り込み（区分チップ・文字入力・件数）／並べ替えできる表
- 操作: 下の段のタブかカードを押すと、要点カードの下の一覧が切り替わり、一覧の頭が見えていなければそこまで送る
- 項目を 1 つ足す: `defs.js` の `SCREENS.<画面>.cards` に 1 行（`group`・`to: { tab, facet }`・`label`・`value` など）。一覧は `tabs` に 1 要素、表の列は `list().columns` に 1 行。格子は `repeat(auto-fill, minmax())` で並びが自動で変わる
- 仮の値: 照合率と適用率は 95% 以上を正常・80% 以上を注意・未満を要確認。未適用・未導入・報告停止・エラーは 1 件以上で注意。「最新版」は観測したバージョンの最大。「確認なしで使われた記録」は新しく作った指標
- 懸念: 下の段のタブと本文の一覧が離れている（タブを押した結果が画面の下で起きる）。帯が 2 本で上端の高さを 100px 使う

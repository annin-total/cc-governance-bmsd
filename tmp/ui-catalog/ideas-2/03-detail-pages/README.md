# 03 要点と詳細を別ページに

- 狙い: 各画面（index / policy）は要点だけ。詳しい一覧は `overview-detail.html` / `policy-detail.html` に分け、2 層を URL で分ける（`#tab:区分` で開く一覧と絞り込みを指せる）
- 受け継いだもの: 04（配色・カード）、05（タブ）、06・14（区分チップ・文字入力・並べ替え）、12（画面ごとの責務の分離）
- 部品: 指標カード（通常・小）／小さな推移／横棒／状態の印／前との差／一覧への入口の表／パンくず／タブ／絞り込み（区分チップ・文字入力・件数）／並べ替えできる表
- 操作: カードは詳しい一覧のページの該当タブへ、区分チップを付けて移る。要点のページの下に一覧の入口（期間と母集団・行数）を並べる
- 項目を 1 つ足す: `defs.js` の `SCREENS.<画面>.cards` に 1 行（`group`・`to: { tab, facet }`・`label`・`value` など）。一覧は `tabs` に 1 要素、表の列は `list().columns` に 1 行。格子は `repeat(auto-fill, minmax())` で並びが自動で変わる
- 仮の値: 照合率と適用率は 95% 以上を正常・80% 以上を注意・未満を要確認。未適用・未導入・報告停止・エラーは 1 件以上で注意。「最新版」は観測したバージョンの最大。「確認なしで使われた記録」は新しく作った指標
- 懸念: 要点と一覧を同時に見られない（行き来が増える）。ページが画面の倍になる（実装ではテンプレートを共通にする）

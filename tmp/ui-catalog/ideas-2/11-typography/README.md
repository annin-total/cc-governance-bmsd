# 11 文字の変奏（04＋05 の合成に、文字組みの切り替えスイッチ）

- **狙い**: 構成と配色は 01（上段 04 のカード・下段 05 のタブ、グレージュ）と同じにして、文字組みだけを 3 通り（ゴシック 13px 基調／見出しだけ明朝／12px 高密度）比べる。ヘッダ右の「文字」で切り替え、`?v=gothic13|mincho|dense12`
- **受け継いだもの**: 04 のカードとトークン、05 の分段タブ、06・14 の文字入力・状態チップ・並べ替え、14 の 1 人 1 行の表
- **部品（7 つ）**: 指標カード／分段タブ／絞り込み（文字入力＋区分チップ＋件数）／並べ替えつきの表／状態の印／小さなグラフ（折れ線・帯・積み上げ・横棒）／棒グラフ（タブ内）
- **項目を 1 つ足す**: `CARDS`・`TABS`・`cols` に 1 要素（10 と同じ）。文字組みは `variant.css` の変数（`--fs`・`--fs-val`・`--head` など 12 個）だけで決まるので、組みを足すのも変数のまとまりを 1 つ足すだけ
- **大きな数字**: 38px（12px 高密度は 30px）、太さ 600。明朝は見出し・カード名・タブ名だけで、数字は常に欧文の書体
- **画像**: shot-1 ゴシック 13px 概況／shot-2 使われ方のカードから一覧を開いた状態／shot-3 適用状況の端末ごとで「未適用」＋文字入力／shot-4 見出しだけ明朝／shot-5 12px 高密度
- **懸念**: 明朝は Windows では游明朝の細さで印象が変わる（未確認）。12px 高密度はカードの中の余白が行の最も高いカードに引っぱられて空く

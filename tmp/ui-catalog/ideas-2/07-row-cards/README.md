# 07 横長の行カード

- 狙い: 指標 1 つを「状態・名前と期間・値・前期間との差と基準・小さなグラフ」の横長の 1 行にし、縦に積む。項目が増えても行が 1 本増えるだけで、列の位置がそろうので値を縦に比べやすい
- 受け継ぎ: 04（配色・差のチップ・スパークライン）、05（下段のタブ）、06・14（絞り込み）。行を押すと、下のタブを条件付きで開く
- 部品: ナビ・指標カード・状態の印（●＋語）・差のチップ・小さなグラフ（推移線・メーター・横棒・積み上げ）・タブ・絞り込み（文字入力＋区分チップ＋カードから付く条件）・表（列見出しで並べ替え）、行カード
- 項目を足す: 指標は `model-*.js` の `METRICS` に 1 行（値・`rule`・開くタブ）、一覧は `TABS` に 1 要素（列は `cols`）、設定は `SETTINGS` に 1 行。格子は `auto-fill` で並ぶ
- 仮の基準（`rule`）: 利用者・セッション・記録は前期間比 −10% 未満で注意／−25% 未満で要対応、コスト +5% 超／+20% 超、照合率 95% 未満／80% 未満、エラー 0 件超／20 件超、欠け 20% 超／50% 超、設定の適用率 80% 未満／75% 未満、未導入 0 人超／5 人超、報告停止 0 台超／10 台超。エラーの行は端末 10 台以上を要対応
- 撮影: shot-1 概況、shot-2 コストの行から日ごとのコスト、shot-3 設定の適用状況で「パッケージマネージャ経由の自動更新」の行＋「user00」、shot-4 設定の適用状況の初期状態
- 懸念: 行が 8 本を超えると上段が 900px に収まらない。推移の系列が無い指標（照合率・欠け）はグラフの形が行ごとにそろわない

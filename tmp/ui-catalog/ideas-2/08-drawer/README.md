# 08 詳細は右の引き出し

- 狙い: 上段は 04 のカードだけにして動かさない。カード（または下の「詳しい一覧」のボタン）を押すと、右から引き出しが出てタブ・一覧・絞り込みを表示する。閉じれば元の 1 枚に戻る
- 受け継ぎ: 04（カード・配色）、05（タブ）、06・14（文字入力・状態の区分チップ・並べ替え）
- 部品: ナビ・指標カード・状態の印（●＋語）・差のチップ・小さなグラフ（推移線・メーター・横棒・積み上げ）・タブ・絞り込み（文字入力＋区分チップ＋カードから付く条件）・表（列見出しで並べ替え）、引き出し（幅 920px、Esc・背景・× で閉じる）
- 項目を足す: 指標は `model-*.js` の `METRICS` に 1 行（値・`rule`・開くタブ）、一覧は `TABS` に 1 要素（列は `cols`）、設定は `SETTINGS` に 1 行。格子は `auto-fill` で並ぶ
- 仮の基準（`rule`）: 利用者・セッション・記録は前期間比 −10% 未満で注意／−25% 未満で要対応、コスト +5% 超／+20% 超、照合率 95% 未満／80% 未満、エラー 0 件超／20 件超、欠け 20% 超／50% 超、設定の適用率 80% 未満／75% 未満、未導入 0 人超／5 人超、報告停止 0 台超／10 台超。エラーの行は端末 10 台以上を要対応
- 撮影: shot-1 概況、shot-2 エラーのカードから引き出し、shot-3 設定の適用状況で「自動圧縮のしきい値」から引き出し＋「未適用あり」、shot-4 設定の適用状況の初期状態
- 懸念: 引き出しが上段の右 2/3 を覆うため、一覧とカードを同時に見比べにくい。幅に収めるため、引き出しの利用者の表では端末数の列を外している

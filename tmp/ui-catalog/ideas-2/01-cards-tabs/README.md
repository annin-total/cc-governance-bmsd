# 01 04＋05 の素直な合成

- 狙い: 上段に 04 の指標カードを 2 群で並べて要点を 1 画面に収め、下段に 05 のタブで詳しい一覧を開く。第 2 弾の基準線
- 受け継いだもの: 04（配色・カードと小さな推移）、05（タブ）、06・14（区分チップ・文字入力・並べ替え、利用者 1 人 1 行の表）
- 部品: 指標カード（通常・小）／小さな推移／横棒／状態の印／前との差／タブ／絞り込み（区分チップ・文字入力・件数）／並べ替えできる表
- 操作: カードを押すと、該当のタブを区分チップで絞った状態で開き、下段へ移る
- 項目を 1 つ足す: `defs.js` の `SCREENS.<画面>.cards` に 1 行（`group`・`to: { tab, facet }`・`label`・`value` など）。一覧は `tabs` に 1 要素、表の列は `list().columns` に 1 行。格子は `repeat(auto-fill, minmax())` で並びが自動で変わる
- 仮の値: 照合率と適用率は 95% 以上を正常・80% 以上を注意・未満を要確認。未適用・未導入・報告停止・エラーは 1 件以上で注意。「最新版」は観測したバージョンの最大。「確認なしで使われた記録」は新しく作った指標
- 懸念: カードとタブの対応が 1 対 1 でない（利用者とセッションが同じタブ）。タブが画面の中ほどにあり、開いても上段の要点と同時には見えにくい

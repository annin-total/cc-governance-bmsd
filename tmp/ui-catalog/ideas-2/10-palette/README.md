# 10 配色の変奏（04＋05 の合成に、配色の切り替えスイッチ）

- **狙い**: 構成は 01（上段 04 のカード・下段 05 のタブ）と同じにして、配色だけを 3 通り並べて選べるようにする。ヘッダ右の「配色」で切り替え、`?v=greige|bluegray|sepia` で指定・画面間で引き継ぐ
- **受け継いだもの**: 04 のカードとトークン・小さな推移、05 の分段タブ、06・14 の文字入力・状態チップ・列見出しの並べ替え、14 の 1 人 1 行の表（利用者ごとタブ）
- **部品（7 つ）**: 指標カード／分段タブ／絞り込み（文字入力＋区分チップ＋件数）／並べ替えつきの表／状態の印（点＋語）／小さなグラフ（折れ線・帯・積み上げ・横棒）／棒グラフ（タブ内）
- **項目を 1 つ足す**: カード＝`overview.js`・`policy.js` の `CARDS` に 1 要素（`group` と開く `tab` を持つ）。タブ＝`TABS` に 1 要素（`table()` が列の定義 `cols` を返す）。表の列＝`cols` に 1 要素。格子は `repeat(auto-fill, minmax(248px, 1fr))`、広いカードは `wide: true`
- **配色を足す**: `variant.js` に 1 行、`variant.css` に変数のまとまりを 1 つ（色はすべて CSS 変数。JS に色を書いていない）
- **画像**: shot-1 グレージュ概況／shot-2 コストのカードから一覧を開いた状態／shot-3 適用状況で「未適用あり」＋文字入力／shot-4 青みの灰／shot-5 セピアとオリーブ
- **仮の値**: 欠けの判定（20% 超で注意・50% 超で要確認）、エラーのカードは常に「注意」、未適用のカードは「要確認」・未導入は「注意」
- **懸念**: グレージュと青みの灰は差が小さい（トーンを 04 から離さない方針の結果）。値は innerHTML で組むので、実装時は文字列の無害化が要る

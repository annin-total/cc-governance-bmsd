# 09 罫線で区切る 04

- **狙い**: 04 の配色のまま、カードの塗り・角丸・影をやめ、墨の罫（群の見出しの下）と細い縦罫・余白だけで区切る。タブも下線だけの文字のタブにして、紙面のような軽さにする
- **受け継いだもの**: 04 のトークン（地だけ一段明るい紙色 `#f4f2ee`）と指標カードの中身、05 のタブ、06・14 の文字入力・状態チップ・並べ替え、14 の 1 人 1 行の表
- **部品（7 つ）**: 指標（罫で区切った区画）／下線のタブ／絞り込み（文字入力＋罫で囲んだ区分チップ＋件数）／並べ替えつきの表／状態の印／小さなグラフ／棒グラフ（タブ内）
- **項目を 1 つ足す**: `overview.js`・`policy.js` の `CARDS`・`TABS`・`cols` に 1 要素。区画の縦罫は各区画の左罫を 1px 重ねて外周を切り落とす方式なので、列数が変わっても端に罫が残らない
- **構成**: 10・11 と同じ JS。見た目の差は `variant.css`（約 30 行）だけ
- **画像**: shot-1 概況／shot-2 エラーの区画から一覧を開いた状態／shot-3 適用状況で「報告停止」の区画から開き文字入力
- **仮の値**: 欠けの判定（20% 超で注意・50% 超で要確認）、未適用は「要確認」・未導入は「注意」
- **懸念**: 区画が押せることが塗りのある 04 より伝わりにくい（右上の「一覧 ↓」と、押した区画の下線だけが手がかり）

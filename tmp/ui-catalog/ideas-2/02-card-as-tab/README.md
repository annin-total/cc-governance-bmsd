# 02 カードがタブを兼ねる

- 狙い: 押したカードの一覧が下に出る（カード＝タブ）。タブの帯をなくし、部品を 1 つ減らす
- 受け継いだもの: 04（配色・カード）、05（タブの考え方をカードに移す）、06・14（区分チップ・文字入力・並べ替え）
- 部品: 指標カード（押せる・通常・小）／小さな推移／横棒／状態の印／前との差／絞り込み（区分チップ・文字入力・件数）／並べ替えできる表
- 操作: 同じ一覧を指すカードはそろって枠が付き（「同じ一覧」）、一覧の見出しの上にどのカードの一覧かを出す
- 項目を 1 つ足す: `defs.js` の `SCREENS.<画面>.cards` に 1 行（`group`・`to: { tab, facet }`・`label`・`value` など）。一覧は `tabs` に 1 要素、表の列は `list().columns` に 1 行。格子は `repeat(auto-fill, minmax())` で並びが自動で変わる
- 仮の値: 照合率と適用率は 95% 以上を正常・80% 以上を注意・未満を要確認。未適用・未導入・報告停止・エラーは 1 件以上で注意。「最新版」は観測したバージョンの最大。「確認なしで使われた記録」は新しく作った指標
- 懸念: カードを持たない一覧は開けない（一覧を足すと必ずカードも要る）。どのカードも押せる見た目のため、要点を読むだけのときに枠の変化が気を引く

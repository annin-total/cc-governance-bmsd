# 06 共通の絞り込みバー

- 狙い: 画面の上に 1 本のバー（期間の表示・文字・状態）を固定し、同じ条件をカードと一覧の両方にかける。設定の適用状況では、絞った利用者だけで適用率のカードを計算し直す
- 受け継ぎ: 04（カード・配色）、05（下段のタブ）、06・14（文字入力・状態の区分）。状態の区分はバーに一本化し、一覧の中には月・分類などの区分だけを残す
- 部品: ナビ・指標カード・状態の印（●＋語）・差のチップ・小さなグラフ（推移線・メーター・横棒・積み上げ）・タブ・絞り込み（文字入力＋区分チップ＋カードから付く条件）・表（列見出しで並べ替え）、共通バー（スクロールしても上に残る）
- 項目を足す: 指標は `model-*.js` の `METRICS` に 1 行（値・`rule`・開くタブ）、一覧は `TABS` に 1 要素（列は `cols`）、設定は `SETTINGS` に 1 行。格子は `auto-fill` で並ぶ。バーの状態の区分は、概況は指標の状態、設定の適用状況は利用者の状態
- 仮の基準（`rule`）: 利用者・セッション・記録は前期間比 −10% 未満で注意／−25% 未満で要対応、コスト +5% 超／+20% 超、照合率 95% 未満／80% 未満、エラー 0 件超／20 件超、欠け 20% 超／50% 超、設定の適用率 80% 未満／75% 未満、未導入 0 人超／5 人超、報告停止 0 台超／10 台超。エラーの行は端末 10 台以上を要対応
- 撮影: shot-1 概況、shot-2 概況で「正常」＋受信と欠けのタブ、shot-3 設定の適用状況で「user00」＋「未適用あり」、shot-4 設定の適用状況の初期状態
- 懸念: 概況の値は利用者別に集計していないため、概況ではバーの文字は項目名・日付にかかる（利用者では絞れない）。バージョンの一覧（端末ごとの集計）にも条件はかからず、その旨を一覧に出している

# 13 一言の要約つき

- 狙い: 要点カードの上に 1〜2 文の要約を置き、画面を開いて最初の数秒で「今どうなっているか」を文で掴めるようにする（第 1 弾 03 の考え方を短く）。要約の中の注意・要対応の語は、押すと該当のタブを開く
- 要約の組み立て: 文を別に書かず、カードの定義から作る。1 文目 = `GROUPS` の `lead` ＋ その群のカードの `says` を「、」でつなぐ。2 文目 = `issue` を持つカードを状態（要対応・注意）で束ね、残りは「ほかの N 項目は正常です」。組み立ては `ui.js` の `summary`
- 受け継いだもの: 12 と同じ構成（04 のカード、05 のタブ、06・14 の絞り込み）に要約を足しただけ。部品は 12 の 6 つ＋要約の 1 つ
- 項目を 1 つ足す: `CARDS` に 1 件。要約に載せたいなら同じ行に `says`（1 文目の句）か `issue`（状態が悪いときの句）を書く。文の側は触らない
- 仮の判定基準: 12 と同じ（欠け 20%／50%、記録数 ±20%、照合率 95%／80%、エラー 1 件以上、適用率 80%／50%、最新版が半数未満）
- 懸念: 注意が増えると 2 文目が長くなる（今の設定の適用状況で 1 行ぎりぎり）。句を並べるだけなので「なぜ」は書けない。1 文目に載せる句を増やすと要約ではなく一覧になるため、群ごとに 2〜3 句までに抑える運用が要る

# 05 状態で束ねる

- 狙い: 上段の指標を定義の基準で「要対応／注意／正常」の束に自動で振り分け、悪いものから目に入るようにする。正常の束は値だけの小さなカードに縮める
- 受け継ぎ: 04（カード・配色）、05（下段のタブ）、14（状態の区分チップで一覧を絞る）。カードを押すと、そのタブを条件付きで開く
- 部品: ナビ・指標カード・状態の印（●＋語）・差のチップ・小さなグラフ（推移線・メーター・横棒・積み上げ）・タブ・絞り込み（文字入力＋区分チップ＋カードから付く条件）・表（列見出しで並べ替え）、束（状態ごとの帯）
- 項目を足す: 指標は `model-*.js` の `METRICS` に 1 行（値・`rule`・開くタブ）、一覧は `TABS` に 1 要素（列は `cols`）、設定は `SETTINGS` に 1 行。格子は `auto-fill` で並ぶ。束への振り分けは `rule` から自動
- 仮の基準（`rule`）: 利用者・セッション・記録は前期間比 −10% 未満で注意／−25% 未満で要対応、コスト +5% 超／+20% 超、照合率 95% 未満／80% 未満、エラー 0 件超／20 件超、欠け 20% 超／50% 超、設定の適用率 80% 未満／75% 未満、未導入 0 人超／5 人超、報告停止 0 台超／10 台超。エラーの行は端末 10 台以上を要対応
- 撮影: shot-1 概況、shot-2 エラーのカードから一覧、shot-3 設定の適用状況で「user0」＋「未適用あり」、shot-4 設定の適用状況の初期状態
- 懸念: 状態が変わるとカードの位置が動く（毎回同じ場所で読めない）。基準の値は仮で、運用で決める必要がある

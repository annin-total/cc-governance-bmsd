# 管理画面のトップのモック

トップに載せる要素・警告の基準・期間（基準日）を決めたうえで、**並べ方**を 3 案比べるもの。**一時的な文書で、採る案が決まったら消す。**

- 正本: `brief.md`（要素・判定・ダミーの値）
- 各案: `ideas/*/index.html`（1 ファイル完結、file:// で開ける）。カードの見た目と値は 3 案で同じ
- 画像: `shots/*-first.png`（1280×800 の 1 画面目）、`shots/*-full.png`（全体）

| 案 | 並べ方 | 1 画面目に収まる要素（`brief.md` の順） |
| --- | --- | --- |
| A 左右分割 | 左にサマリー、右にカード | 1〜10 |
| B 上に要約・下にカード | サマリーは 3 行で折りたたみ、下にカード | 1〜9 |
| C 警告を先頭に | 要確認・注意の一覧、折りたたんだサマリー、カード | 1〜6・8・9（7 は上半分） |

## 比べるときの注意

- 金額・モデルの割合は仮の値
- 期間のコストは、営業日数が違う（今期 3・前 2）ため素の率 +68.0% を出し、状態は 1 営業日あたり +12.0% で判定している
- 増減の色は、悪化が紫系、改善が青系。状態（枠・点と語）とは別の手段で示す
